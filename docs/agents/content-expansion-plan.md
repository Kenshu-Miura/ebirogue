# 敵・武器・盾・カード・指輪の追加計画（シレン6 wiki 調査）

作成: 2026-10-14。開発者の方針: BOT や難易度の調整より、敵とアイテムの追加を優先する。

参照元: [風来のシレン6 攻略 wiki](https://shiren6.game-info.wiki/)（モンスター Part1〜3・武器・盾・巻物・腕輪の各ページ、2026-10-14 時点）。

## 方針

- wiki は**仕様の参考**にとどめる（`docs/agents/README.md` の外部コードの参照ポリシーと同じ扱い）。効果は自分の言葉で書き直し、数値は ebirogue の規模（初期HP40、武器の攻撃力2〜12、敵の HP 8〜68 など）に合わせて決める。原作の数値を写さない。
- 名前は海老さんの世界観に合わせた**仮名**。開発者が変えてよい。原作名は「元ネタ」の列にだけ書く。
- 敵は `AGENTS.md` の規則どおり、基本種・第2段階・第3段階の3体を1系統として追加する。上位種は基本種の画像の色相違い。
- 巻物は「カード」、腕輪は「指輪」として追加する。カードは `img/card.png`、指輪は `img/ring.png` を共用する（未識別の見た目で正体がわからないようにするため）。武器・盾・敵は個別の画像を Codex が作る（`img-content-expansion.md`）。
- 1つの担当で触る範囲を小さくし、共通の仕組みは先に Claude Code が直列で作る（下の「共通基盤」）。

| 対象 | 理由 |

| 印・共鳴・銀封印・印増大・印消し・銀はがしの巻物、マゼルン種 | 印と合成の仕組みが無い。合成（Priority B）の後 |

## 共通基盤（Claude Code、直列、ブランチ `agent/content-foundation`）

追加する要素の多くが使う仕組みを先にまとめて作る。並列の担当が同じ箇所を別々に作らないようにするため。

| 記号 | 内容 | 使う要素 |
|---|---|---|
| F1 | 装備能力のフック: 武器の「攻撃前の倍率」「命中後」「撃破後」、盾の「被ダメージの補正」「倒れる直前の判定」、指輪の能力 ID（`Accessory.Abilities`）と毎ターンの処理・状態異常の無効化の問い合わせ（例: `g.playerImmuneTo(状態)`）。鼓舞の指輪を名前判定から能力 ID へ移す | 武器・盾・指輪のほぼ全部 |
| F2 | 敵の属性の追加: 甲殻（カニ・ヤドカリ・貝）、爆発（ウニ・フグ）、浮遊（クラゲ）。既存の敵へ付与し、特効の判定を属性の一覧から引く形にする | 甲殻斬り・ウニ割り・空の刃、新しい敵 |
| F3 | 位置を動かす共通処理: 吹き飛ばし（N マス、壁や敵に当たると固定ダメージ）、引き寄せ（途中の罠を発動）、持ち物を落とす（前方へ1〜2個）。「不動」「受け身」の能力で防ぐ問い合わせ口を用意する | ウミダンゴ・カエルアンコウ・巨大ハリセン・不動の盾・ざぶとん |
| F4 | 敵の痛恨の一撃（たまに通常攻撃が1.5倍）と、敵が通常攻撃をかわす確率 | オオハサミガニ・スナモグリ・痛恨よけの盾・痛恨・諸刃の指輪 |
| F5 | アイテムの床出現をカテゴリ別の重みにする（武器・盾・カード・指輪・食料・薬・杖・壺・矢・お金のそれぞれの合計の割合を決め、カテゴリ内で抽選）。**今のままでは全テンプレートが同じ重みなので、78個追加すると食料と回復薬の出現が約半分になり、餓死が急増する** | 全アイテム |

完了条件は通常どおり（gofmt、2系統のテスト、`TestSimSmoke`）。F5 の前後で `TestSimBatch` を回し、カテゴリ別の出現数が変わっていないことを確認する。
