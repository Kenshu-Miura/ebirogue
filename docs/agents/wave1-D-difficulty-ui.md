# wave1-D: 難易度選択・クリア画面・冒険の記録（Codex 用）

ブランチ: `agent/wave1-D-difficulty-ui`
前提: フェーズ0（P0-3 入力抽象化、P0-5 冒険結果、P0-6 難易度の骨格）が master にマージ済みであること。
最初に `AGENTS.md` と `docs/agents/README.md` を読み、並列作業のルールに従うこと（`AGENTS.md` と `IMPLEMENTED_FEATURES.md` は編集しない）。

## 作るもの

1. **難易度選択画面**: 新しい冒険を始めるとき（初回起動、死亡後、クリア後）に表示する。中断データから再開するときは表示しない。
   - 初級（10階のボスを倒すとクリア）／中級（20階）／上級（30階）。矢印キーで選び `Z` で決定。
   - 前回選んだ難易度をカーソルの初期位置にする（この記憶だけは `GameSettings` に保存してよい）。
2. **クリア画面**: 目標階のボスを倒したときに表示する。難易度、ターン数、レベル、シードを表示し、`Z` で難易度選択画面へ戻る。
3. **HUD**: 現在の難易度と目標階を表示する（例: 「上級 12/30F」）。
4. **冒険の記録**: メニューに「記録」を追加し、保存済みの `RunResult` を新しい順に一覧表示する（日時、難易度、結果、到達階、死因）。
5. **ヘルプ**: クリア条件と難易度の説明ページを追加する。

## 仕様

- 入力は P0-3 の `InputSource` 経由で読む（`ebiten.IsKeyPressed` を直接呼ばない）。
- ウィンドウの描画は `draw_ui.go`、入力処理は `input.go` の既存パターンに合わせる。表示中の判定フラグを追加した場合は、`Update()` の入力受付条件にも追加する。
- BOT（P0-7）が難易度選択画面を通過できるように、BOT のキー操作ヘルパーを更新する。
