# wave10-C: アイテム・敵・罠の図鑑と発見率（Codex 用）

ブランチ: `agent/wave10-C-encyclopedia`
前提: **段9が master に統合されていること。** 10-A（モンスターハウス）・10-B（店。店主 126〜128 が加わる）と並行するので、図鑑の対象はテンプレートの表から自動で作り、新しい ID が入っても手直し不要にする。`AGENTS.md`（セーブ・設定システム）、`docs/agents/README.md`、`docs/agents/feature-completion-plan.md` を先に読む。

## 作るもの

1. **発見の記録**: 冒険をまたいで残る `ebirogue_codex.json`（`storageRead`/`storageWrite` を通す。WASM は localStorage。`g.persistent` のときだけ書く）。
   - アイテム: 見た（床・持ち物で表示された）・識別した。
   - 敵: 出会った（画面に見えた。化けた敵は正体を現したときに正体の方を記録）・倒した数・倒された数。
   - 罠: 発見した・踏んだ。
2. **図鑑の画面**: メニューに「図鑑」を足す（「記録」の隣）。アイテム（カテゴリ別）・敵（系統別、基本種→第2→第3段階の順）・罠のタブ。未発見は「？？？」で、ID 順に並べて抜けがわかるようにする。発見済みは画像・名前・説明（既存の説明文。アイテムは識別済みのときだけ）・敵の能力値と倒した数。
3. **発見率**: タブごとと全体の「発見 n / 全 m（p%）」。ボス・店主も対象に含める。デバッグビルドや BOT でしか出ない ID（あれば）は対象から除く。
4. 操作: ↑↓・←→でタブとページ、`X` で戻る、`C` で閉じる。キー名は `g.keyGuide(...)` を通す（キー設定の規則）。640x480 の窓に収まること。

## 守ること

- 記録の書き込みはフロア移動・冒険の終わりなどにまとめて行い、毎ターン書かない。
- 図鑑のデータは純粋なファイル（タグなし）で扱い、記録の結合・発見率の計算・壊れたファイルの扱いを単体テストする。
- 冒険の乱数・ターン進行を変えない（BOT の結果がベースラインと一致すること）。
