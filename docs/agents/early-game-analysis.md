# 序盤（1〜5階）の死亡率の原因調査

調査日: 2026-10-14（毒のパワー低下への置き換え `4577305` の後の master）

## 結論

- **前提の数字の読み違い**: 「1階の死亡率 26.7%・4階 51%」は**全性格の合計**の値で、`random`（1階で9割が死ぬ）や `aggressive` を含む。expert だけを見ると 1階 4.0%・2階 4.8%・3階 14.4%・4階 32.7%・5階 33.0% で、序盤の壁は 1〜2階ではなく **3〜5階**にある。
- 改善前の expert の 1〜5階の死亡（2000冒険中1294）の 71% は BOT の判断ミスに分類できた。最大の原因は**HPが減ったまま探索を続ける**こと（休憩しない）と、**イシガニの投石が届く範囲を BOT が知らない**こと。
- BOT を改善すると（ゲームの数値は変えず）、1〜5階の死亡は 1294 → **1091（−15.7%）**、4階 32.7% → 27.1%、5階 33.0% → 22.2%。
- 改善後も残る死亡の 56% は「避けにくい死」で、主因は**自然回復が最大HPに関係なく5ターンに1**であること、**イシガニの投石（壁越し・威力12）**、**複数の敵に囲まれる**こと。数値変更案のうち効果が大きく目標曲線も崩さないのは**案1（自然回復を最大HPに比例）**。決定は開発者に任せる。

## 計測方法

- `go test -run TestEarlyDeathAnalysis -count=1 -timeout 0 . -args -sim.early=2000 -sim.out=reports`（`sim_early_test.go`）。expert・上級・シード1〜2000。1回 約1.5〜2分。
  - 各ターンの状態（HP・最大HP・満腹度・レベル・パワー・攻撃/防御・BOT が選んだ行動・隣の敵・5マス以内の敵の数・遠距離攻撃が届くか・発見済みの階段までの距離・所持品の分類ごとの数）を記録し、死亡直前の40ターンを残す。各階に着いたときの床の食料・回復の道具の数も数える。
  - 「遠距離攻撃が届くか」はゲーム本体の `canEnemyUseRangedAttack` で判定する（BOT 自身の判定とは独立。改善前後で同じ基準）。
  - BOT の行動は `bot.act`（expert が選んだ行動の分類: melee・explore・toItem・rest・leaveFire など）。
- 1件の確認: `go test -run TestEarlyDeathDump -count=1 . -v -args -sim.earlydump=<シード>` で死亡直前のターンを1行ずつ表示する。
- 同じシードなら結果は完全に再現する（改善前の BOT を一時的に再現して測り直した値が初回の値と一致した）。

## 分類基準

死亡ごとに上から順に判定し、最初に当てはまったものに分類する。(a) をすべて調べてから (b) を判定する。

### (a) BOT の判断ミス（BOT の改善で防げる）

| 分類 | 判定 |
|---|---|
| 不利なカードの被害 | 自爆系の死因、または不利なカードを使ってから100ターン以内に同じ階で死亡（既存の `mistakeKind`） |
| 食料を持ったまま餓死 | 餓死で、腐っていない食料を所持 |
| 回復の道具を持ったまま死亡 | 餓死・突風以外で、回復の道具（`itemRoles` の回復）を所持 |
| 止める・倒す道具（カード・薬）を持ったまま死亡 | 敵による死亡で、その場で使えた道具を所持: 黒炎弾・真空斬り・全滅・睡眠・混乱・目潰し・金縛りのカード、睡眠薬・混乱薬・目潰し薬。封印の杖・シフトチェンジの杖・ジェノサイドのカードは使える場面が限られるので数えない |
| HPが減ったまま探索を続けて交戦 | 直前15ターンのうち、倒した敵が最初に隣に来た（遠距離なら攻撃が届いた）ターンの HP が最大HPの50%未満で、その前の3ターン以上は隣に敵がおらず、満腹度20以上（休めたのに休まなかった） |
| 射線に立ち続けた | 遠距離攻撃で死亡し、直前10ターンのうち3ターン以上、攻撃が届く位置で「近づく・攻撃・射撃・投擲」以外の行動をしていた |
| 階段で逃げられたのに戦った | 直前10ターンに、HP 50%未満・隣に敵がいる状態で階段の上にいた |

### (b) 適切に動いても避けにくい死（ゲームの数値の問題）

| 分類 | 判定 |
|---|---|
| 食料が無く餓死 | 食料を持たずに餓死 |
| 罠 | 罠による死亡 |
| 満タンでも勝てない強さの敵 | 倒した敵と満タンから通常攻撃だけで戦うと、倒すまでに受けるダメージの見込みが最大HP以上 |
| HP半分以上から3ターン以内に倒れた | 3ターン前の HP が最大HPの50%以上 |
| 複数の敵に囲まれた | 直前4ターンに隣の敵が2体以上 |
| 連戦で消耗（道具なし） | 上のどれにも当たらない |

「射線に立ち続けた」には、HP が少なくなってから射程の外へ下がる途中で倒れたもの（下がるのに数ターンかかる投石）も含まれる。BOT の選択の結果ではあるが、イシガニの投石の射程（壁越しに5マス）が広いことによる面もある。

典型例（シード1、5階・Lv13）: HP 53/127（42%）で探索を続け、視界の外のイシガニの投石を約15ターン受け続けた。BOT は投石が直線上でしか届かないと判断していたため、射程にいることに気づいていない。HP が40%を切ると「近づいて倒す」もやめ、そのまま倒れた。止める道具と黒炎弾を持っていた。

### 見つかった BOT の弱点

1. **休憩しない**: 敵がいなくても HP が減ったまま探索・道具拾いを続ける。自然回復（5ターンに1）を待てば満腹度の消費は 1HP あたり0.5で済む。
2. **投石の射程を知らない**: ゲームではイシガニの投石は2〜5マス以内なら向き・壁に関係なく届く（`canEnemyUseRangedAttack`）が、BOT の `inRangedFire` は直線上だけを見ていた。
3. **HP が少ないときに射線から出ない**: HP 40% 未満では遠距離の敵へ近づくのをやめるが、離れもしない。
4. 倍速の敵（ハヤテシャコ）の被ダメージを1回分で見積もっていた。

## BOT の改善（`bot_expert_test.go`、ゲームの数値は変更なし）

| 改善 | 内容 |
|---|---|
| 休憩 | 6マス以内に敵がいない・遠距離攻撃が届かない・この階に来て900ターン未満・満腹度と手持ちの食料の合計が30超のとき、HP 60% 未満で足踏みを始め、90% まで続ける（`expertShouldRest`） |
| 投石の射程 | `inRangedFire` で投石は直線でなくても届くとみなす |
| 射線からの退避 | HP 40% 未満で遠距離攻撃が届く位置にいたら、睡眠・混乱・目潰しのカード（部屋の敵全員）を使い、無ければ届かないマスへ下がる |
| 強敵への道具 | 強敵に黒炎弾が無ければ真空斬りを使う。倍速の敵は1ターンに2回分の被ダメージで見積もる |
| 記録 | 選んだ行動を `bot.act` に残す（分析用、行動は変えない） |

試して効果が無かった・悪化したため採らなかったもの: シフトチェンジの杖を逃走に使う（死亡が約+10%。変えた先の敵が強いことがある）、回復手段が無い低HPで黒炎弾・真空斬りを使う、HP 40% 未満のとき射線のマスを通らない移動、「通常攻撃だけでは負けそう」な戦闘で止める道具を先に使う（いずれも差が ±1% 以内）。

- 死因の上位: イシガニの投石 266（24%）、火吹きイカ 68、毒ヘビ 67、ハヤテシャコ 65、マホウクラゲ 53。
- 回復・止める・倒す道具を1つも持たずに死亡 41.5%。平均パワー 3.9。

数値として見えた問題:

1. **自然回復が最大HPに比例しない**: 5ターンに1回復で固定。Lv13 の最大HP 127 では、半分から全回復に約320ターン（満腹度32）かかる。最大HP 40 の Lv1 と同じ速さなので、レベルが上がるほど休憩の効率が落ち、連戦で削れたまま次の敵に会う。
2. **イシガニの投石**: 威力12（イシガニの通常攻撃7より強い）で、2〜5マス以内なら壁・向きに関係なく届く。3〜5階の死因の約4分の1を占める。
3. **4階で遠距離の敵が強くなる**: 遠距離攻撃を持つ敵の出現重みは3階 約24%（ハリセンボウ・イシガニ・火吹きイカ）、4階 約29%（イシガニ・バクダンウニ・火吹きイカ・マホウクラゲ）。割合の増加より、威力14〜16の炎・魔法弾・爆発弾の敵が主になることが大きい。
4. **パワーが下がったまま戻らない**: 毒ヘビの毒攻撃（30%）・毒矢の罠・腐った食料で下がり、戻す手段はパワーアップのカードなどに限られる。死亡時の平均は 3.9〜4.7。
5. 食料（1階あたり床に約0.4個）は expert の序盤では足りている（餓死は 1%未満）。回復の道具は約0.7個。

## 数値変更案（未実装）

想定効果は、改善後の BOT で一時的に数値を変えて同じ2000冒険を測った値（変更はコミットしていない）。目標曲線への影響は不死モード（expert・上級・252冒険）の到着時レベルで測り、通常の BOT への換算は改善後の BOT の実測比（10階: 通常 13.5 ÷ 不死 17.2 ≈ 0.78）を使った。

改善後の BOT・数値は現状のままの値（比較の基準）: 1〜5階の死亡 1091、不死モードの到着時レベル 10階 17.2・20階 30.5・30階 42.3（換算 13.4・23.8・33.0）。

| 1 | 自然回復を「5ターンごとに max(1, 最大HP/40)」にする（最大HP 40 で1、120 で3） | **733（−33%）** | 16.8%・11.9% | 19.4 / 33.6 / 47.3 | 15.1 / 26.2 / 36.9 |
| 2 | イシガニ系の投石の威力 12 → 8 | 1012（−7%） | 25.3%・21.3% | （経験値は変わらないので変化なしと推定） | 13.4 / 23.8 / 33.0 |
| 3 | 1〜5階だけ湧き間隔を1.5倍（20〜30 → 30〜45ターン） | 798（−27%） | 19.0%・17.2% | 16.8 / 30.0 / 41.5 | 13.1 / 23.4 / 32.4 |
| 4 | 火吹きイカ・マホウクラゲを4階の出現テーブルから外す（5階からにする） | 1086（±0） | 24.3%・24.7% | 17.5 / 30.9 / 42.4 | 13.7 / 24.1 / 33.1 |
| 5 | 毒ヘビ系の毒攻撃の確率 30% → 15% | 1042（−4.5%） | 25.6%・22.4% | （変化なしと推定） | 13.4 / 23.8 / 33.0 |
| 6 | レベルアップでパワーが1戻る（最大パワーまで） | 未測定 | — | 変化なしと推定 | — |

目標曲線（到着時 10階 Lv13〜16・20階 Lv22〜26・30階 Lv30〜35）との関係:

- **案1**: 序盤の死亡を最も減らす。休憩の時間が短くなり探索と撃破が増えるため、到着時レベルが上がる（換算 15.1 / 26.2 / 36.9）。10階は範囲内、20階・30階は上限をわずかに超える。回復量を 最大HP/50 程度に弱めるか、経験値テーブルで1〜2レベル分戻せば範囲に収まる見込み。
- **案2・5**: 経験値の入り方を変えないので曲線への影響はほぼ無い。効果は小さい（−7%・−4.5%）。
- **案3**: 効果は大きいが、倒す敵が減って到着時レベルが下がる（10階 換算13.1 で下限ぎりぎり）。経験値の補正とセットでないと曲線が下へずれる。
- **案4**: 4階の死亡が5階へ移るだけで合計は変わらない。単独では勧めない。
- **案6**: パワーの低下（死亡時 平均3.9）を和らげる。測っていない。毒をパワー低下に変えた直後なので、効果を見てから判断するのがよい。

### 推奨

1. **案1（自然回復を最大HPに比例）を第一候補**とする。効果が最も大きく、原因（レベルが上がるほど回復が相対的に遅くなる）に直接効く。到着時レベルが目標の上限を少し超えるので、回復量の係数（/40〜/50）か経験値で調整する。
2. 投石の死因が突出しているので、**案2（投石の威力 12 → 8）**を合わせる。曲線への影響が無い。
3. 案3・4・5 は案1の後に再計測してから判断する。

決定後は、変更を入れてから `TestEarlyDeathAnalysis` と `TestSimBatch`（通常・不死モード）を測り直し、この文書の数値を更新する。
