## 変更概要

- `terrain.go` に特殊地形の生成・出現率・通行判定を集約した。水路は4階、割れた壁は2階、隠し通路は6階から。ボス階には生成しない。
- 配置済みのプレイヤー・階段・敵・道具・罠の座標を保護して生成。水路は部屋床の1/4以下、各タイルの追加時に全通常歩行マスの連結性を確認する。既存通路と部屋中心は残す。
- 水路はプレイヤーと普通の敵の通行を防ぎ、視界と飛び道具を通す。水棲属性を魚・エイ・タコ系の系統表へ追加し、上位種へ継承。既存の浮遊属性を持つクラゲも通れる。混乱・目潰しの敵の移動にも適用した。
- 水に着地した投擲・矢・壺とその中身は消える。水中で倒した敵の盗品も消える。壺の中身の散乱は通行できないマスを避ける。
- 割れた壁は部屋の壁と通路脇に生成。通常攻撃・つるはし・敵の爆発・地雷・爆発の指輪・自爆のカード・爆発弾で通路になる。外周は掘れない。
- 隠し通路は壁として描画し、敵は通れる。正面への通常攻撃（調べる）で1/2の確率で発見する。あかりのカードと透視の指輪でも発見。発見した部分は通路・踏破済みとなり、ミニマップへ出る。
- ワールド描画・ミニマップ・ヘルプ・射線予測を追加。水路はミニマップで水色、割れた壁は黄土色、未発見の隠し通路は壁扱い。
- 中断セーブは既存の `[][]Tile` を利用し、バージョンを変更していない。新地形を含むセーブと従来地形のみのセーブを読み戻すテストを追加。
- BOT の経路探索は既存の `Blocked` 判定で水路を避ける。敵が合法的に水路・隠し通路へ入る場合だけ不変条件の壁判定を許可した。
- BOT が見つけた「水中のイレカエダコが海老さんを水路へ場所替えする」問題は `regression_test.go` で失敗を再現後、場所替え先のプレイヤー通行判定を追加して修正した。
