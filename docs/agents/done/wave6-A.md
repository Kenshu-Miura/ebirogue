## 仕様の判断

- HPの半分・1/4は整数除算で判定。奇数の最大HPでも指定の割合以下の整数HPが閾値になる。
- 1回の被弾で両閾値をまたぐと膨張メッセージを出さず自爆だけ予約。OnDamaged 内では敵を削除しない。
- エイの3回目の被弾は帯電開始だけ。放電は既に帯電している状態で受けた次の被弾から。
- 帯電の10回目の行動で解除し、その回は通常行動へ戻る。睡眠・混乱などは既存の共通AI処理が優先され、Behavior を呼ばない回は Timer が減らない。
- 封印中のフグは膨張済みでも通常行動する。エイは帯電したまま固有能力を使わず、封印中は Timer が減らない。
- 盾・ダメージ・自爆・表示名・乱数は指定された共通処理を使う。通常の固定攻撃共通処理に合わせ、雷/放電は聖域で防がれる。爆発は聖域上でも被害を受ける。
