# wave1-A 完了報告

## 変更概要

- ブランチ: `agent/wave1-A-move-traps`。罠ID 5（ワープの罠）、6（落とし穴）、7（トラバサミ）を追加。既存テンプレート・抽選一覧の順序を維持して末尾に追記した。
- 効果は `move_traps.go` に分離。ワープ先選択・落下ダメージはタグなしの純粋関数へ切り出し、注入可能な乱数で検証する。ゲーム中は冒険の乱数源、初期配置はフロア生成用の乱数源を使う。
- ワープは現在位置・敵・壁・階段を除いた同階の床から抽選する。候補が無い場合は移動せず終了する。視界・探索済み状態・ミニマップを更新する。着地点の罠の連鎖発動や自動拾得は追加していない。
- 落下ダメージは共通の `rollDamage` を使う防御無視の4〜5ダメージ。`damagePlayer` と `trapSource(6, "落とし穴")` で死因を記録し、死亡時は階を移動しない。
- 階段と落とし穴で `beginFloorDescent` を共用し、既存の暗転・フロア初期化・到着時オートセーブへ接続する。ボス階（撃破後も含む）と30階以降では落下を禁止。初期配置・敵の罠設置・ワナのカードの各生成経路でも落とし穴を抽選から除外する。9→10、19→20、29→30階への落下は許可。
- `StatusAilments.BearTrap` を通常版・スタブ版に追加。移動を試みるとメッセージを出し1ターン消費する。混乱による歩行も止める。通常の状態減算で解除し、攻撃・道具使用・足踏みは許可する。HUDとヘルプに説明を追加。
- 罠ID・発見状態は既存のセーブ変換、残りターンは既存の `StatusAilments` 保存を通じて復元できる。可変フィールドの追記は後方互換（旧JSONでは0）なのでセーブバージョンは変更しない。
- `AGENTS.md` と `IMPLEMENTED_FEATURES.md` は編集していない。
