# expert BOT の立ち回り・道具の改善（agent/bot-tactics）

日付: 2026-10-15。`agent/bot-food` の先から切ったブランチ。調査は `docs/agents/bot-strategy-research.md`。
変えたのは BOT（`bot_test.go`・`bot_expert_test.go`、新規の `bot_tactics_test.go`・`bot_expert_items_test.go`・
`bot_tactics_behavior_test.go`）だけで、ゲーム本体は変えていない。BOT は今までどおり仮想入力で本物のメニュー経路を操作し、
乱数は決定的（改善をすべて切ると改善前と1冒険ずつ同じ結果になることを確かめた）。expert 以外の性格の結果は改善前と同じ。

## やったこと

### 1. 立ち回り（`bot_tactics_test.go`）

- **通路へ下がる**: 距離4以内の起きている敵が2体以上で、今いるマスに隣から攻撃できるマスが3つ以上（部屋の中）なら、
  隣から攻撃できるマスが2つ以下のマス（通路・入口）へ下がる（隣に敵がいなければ5歩、いれば2歩以内）。
  着いたら敵が来るまで足踏みで待つ（最大8ターン。待ち切ったら普段どおり）。ボス戦・聖域の上・射線の中では下がらない。
- **先手**: 隣に敵がいなくて距離2に敵がいれば足踏みで待つ（最大3ターン）。倍速・遠距離攻撃・膨らんだフグ／帯電したエイは待たない。
- **道具を早めに使う**: 隣と距離2の起きている敵を、倒しやすく痛い敵から通常攻撃だけで順に倒すときの被ダメージ
  （命中率90%込み）が今の HP 以上なら、ゾワゾワ（隣に2体以上）→ 全滅・真空斬り（隣に2体以上）→ 止めるカード・薬 →
  自爆（隣に2体以上で HP 50% 以上）→ 黒炎弾（一番痛い敵へ）→ 全滅・真空斬り → 回復（HP 60% 未満）→
  シフトチェンジの杖（HP 50% 未満、距離3以上の敵と入れ替わる）→ 聖域のカードを置く（HP 50% 未満）の順に使う。
- 殴る相手は、角を挟んで殴れない斜めの敵を除いて選ぶ（入口に立つと、強敵が斜めにいるだけで殴れずに行き詰まっていた）。

### 2. 道具（`bot_expert_items_test.go`）

- **指輪**: `ringValues`（`itemRoles` と同じテンプレート ID の表）で価値を付け、空いた枠へ、または価値の低い指輪と替えて付ける。
  回復10・鼓舞9・睡眠よけ7・混乱よけ6・毒消し/胃拡張/浮遊5・百発百中/弾きよけ/錆よけ/しあわせ4・連射（矢を装備していれば6）…。
  呪われた5種、高飛び・魔物呼び・罠増し、爆発・諸刃・すれちがいは付けない（−1）。
- **封印の杖**: 直線上（10マス）に、能力（特殊攻撃・遠距離攻撃・固有の行動・被弾時の反応）を持つ強敵・遠距離攻撃の敵・
  危ない状態の敵がいれば振る（ボス・打ち返す敵・封印済みは除く）。**シフトチェンジの杖**は上の「道具を早めに使う」の終わりだけ。
- **ゾワゾワ・自爆・聖域**: 上の「道具を早めに使う」の中で使う。聖域の上では、隣に敵がいなければ HP 90% まで休み、隣に来た敵は殴る。
- **ウインナー化**: 満腹度20以下で食料（壺の中も含む）が無いとき、価値の一番低い道具をウインナーにする。
- **大部屋**: 満腹度15以下で食料が無く、階段が見つかっていないか20歩より遠く、近くに敵がいない、ボス階でないとき。
- **白紙のカード**: 近くに敵がいなければすぐ書き込む（回復の道具が無ければ完全回復、あれば全滅を選ぶ）。
  ただし下の「ゲームの不具合」のとおり、今は必ず黒炎弾が書き込まれる。
- **保存の壺**: 食料を2つ以上持っていれば1つを残して壺へ入れ、満腹度20以下で持ち物に食料が無ければ壺から出す。
  階段を降りる・休む判断の食料の見積もりに壺の中身も数える。壺拡大のカードは保存の壺を持っていれば読む。中身のある壺は手放さない。

### 3. 持ち物の入れ替え（`bot_expert_items_test.go`）

- 価値の表 `itemValue` を1つにまとめた（大きいほど手放さない）。装備中・食料・回復・中身のある壺は手放さない。
  攻撃70・逃走65・強化50・白紙75・聖域60・ゾワゾワ55・ウインナー化45・自爆40・大部屋35・保存の壺25・指輪15+価値・矢20、
  予備の武器・盾は種類ごとに一番良い1つが25でほかは5、呪われた予備は1、不利なカード0、バクチ1・吸い出し2。
  腐ったウインナーは普通の食料が2つ以上あれば30。
- 満杯のとき、床の道具の価値が持ち物の最低より5以上高ければそこへ向かい、足元メニューの「交換」で入れ替える。
  不利なカード（価値0）は拾いに行かない。手放した道具は同じ階で拾い直さない（今までの「階とテンプレート ID」の記録）。

### 4. 盾

- 使い捨ての盾はボス戦のときだけ使い、それ以外では普通の盾へ戻す。能力のある盾から乗り換えるのは強化値込みの防御力が2以上上がるときだけ。

計測用に `-bot.off=<名前,...>` で改善を個別に切れる（`retreat` `ambush` `saveitem` `rings` `canes` `zowazowa` `selfdestruct`
`sanctuary` `sausage` `bigroom` `blank` `pot` `swap` `shield`）。

## ゲームの不具合（BOT とは別。ゲーム本体は直していない）

1. **白紙のカード**: 持ち物の行動メニューで「使う」を Z で決めると、同じフレームで書き込み画面の Z も処理され（`main.go` の
   `Update` が `handleInventoryInput` の後に `handleBlankCardInput` を呼ぶ）、一覧の先頭の**黒炎弾が必ず書き込まれる**。
   人も同じ。書き込み画面を開いたフレームでは Z を受け付けないようにする（足元メニューの `groundMenuJustOpened` と同じ形）とよい。
   BOT のテスト `TestExpertWritesBlankCard` は、直ったときにも通るように「白紙のまま残らない」ことだけを確かめている。
2. **足元の「交換」の後に状態が残る**: `executeItemSwap` の後も `GroundItemActioned` が true のままになり、次に持ち物の食料・薬・
   カードを使うと `determineItemSource` が床の道具を参照して panic する（床に道具が無いと index out of range）。人も「交換」の
   直後に持ち物を使えば起きる。BOT は交換の後にメニューを開いて閉じ（C キーの処理で false に戻る）避けている。
   `executeItemSwap` の最後で `GroundItemActioned = false` に戻し、回帰テストを足すとよい。
