## 変更概要

- `trap_interaction.go` に敵・着地・爆発の罠処理を追加。`mapTrapTemplate.EnemyEffect` に敵用の効果を登録し、プレイヤー用の効果と分離した。
- 歩行・混乱・目潰し移動・壁抜け・ワープ・位置交換・吹き飛ばしの着地から Action を予約。Action の Execute で ID と座標から敵を引き直すため、移動ループ中には敵を削除しない。掘削・逃走も既存の移動ヘルパー経由で対応。
- 浮遊・ボス・罠設置系・壁中・未解除の道具/階段擬態は踏まない。不発率は罠の既存値。自然作動は視界内で成功したときに発見され、投擲着地は不発でも発見される。
- 睡眠10・鈍足10・トラバサミ6を共通 API で付与。敵のトラバサミをターン経過で解除し、拘束中は移動しない（隣接攻撃は可能）。倍速の2回目は1歩目の罠を解決してから実行する。
- 毒矢5ダメージ、物理罠は既存の基礎威力と敵の防御力で計算。ワープは同じ階の空き床、落とし穴は経験値なしで消える。サビ・装備はずし・腐敗・散乱は敵には無効で残る。
- 自然作動の撃破は経験値なし、海老さんの投擲・矢・爆発での作動は経験値あり。どちらも OnDefeated を呼ぶ。落とし穴は常に経験値なし。
- 投擲・矢は着地アニメーションの終了時に Action を予約し、着地地点だけ作動。杖の魔法弾と通過地点は対象外。
- 大型地雷・敵の範囲爆発・爆発の指輪で地雷系が誘爆。地雷系は爆発前に除去し、再帰の深さは3まで。範囲内のほかの罠は消える。
- 罠のヘルプに攻略への利用を1行追加。
- `AGENTS.md`・`IMPLEMENTED_FEATURES.md`・`STATUS.md` は変更していない。新規 ID・画像・セーブ形式の変更なし。

## 未決事項・統合時の注意

- wave8-A 統合前のため、毒矢の敵への効果は指示書どおり5ダメージのみ。攻撃力低下・回復封じの罠15は追加していない。統合時に必要なら wave8-A の API と結び付ける。

- 着地の判定は元の飛行の終点で行う（床の道具との重複で配置先をずらす場合も、その終点の罠を作動させる）。
- 倍速で踏んだ罠によって敵が消えたりワープした場合、残りの1行動は行わない。不発やダメージだけなら2回目の行動を続ける。
