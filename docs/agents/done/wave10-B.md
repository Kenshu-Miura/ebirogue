## 変更概要

- **値段表**（`item_prices.go`、タグなし・純粋）: 全アイテムテンプレートの買値の基準 `itemBasePrices`（ID ごと）と、
  強化値・呪い・杖の回数・壺の容量・矢の本数で値段を変える `itemBuyPriceFrom`、売値 `itemSellPriceFromBuy`（買値の半分）。
  値段の無いテンプレートがあると `TestItemPriceTableCoversAllTemplates` が落ちる。ゲーム側の入口は `shop.go` の
  `itemBuyPrice(item)`・`itemSellPrice(item)`（壺は自分の中身の売値も足す）。
- **店の部屋**（`special_rooms.go`・`shop.go` の `placeShop`）: 3階から 10%（`shopChance`。ボス階と1〜2階は0）で、
  開始地点・階段の無い部屋を1つ店にする（`Room.Role = RoomRoleShop`）。部屋の中の道具・罠・敵は取り除き、
  床に商品 5〜12個（`pickFloorItemID` の階層別の抽選、小銭は引き直す）を値段付きで置く。店主（126）は最初の出入口の
  内側のマスの壁に沿った隣に立つ（出入口の内側のマスには何も置かず、通り道をふさがない）。店の部屋の中には地形を置かない。
- **買う**: 商品（床の `BaseItem.ShopPrice > 0`）を拾うと未払い（持ち物の `ShopPrice > 0`）になり「店主「〜は○円です」」。
  店主に隣で Z（話しかける。攻撃せず、ターンは進まない）か、店の出口（壁の線上の通路のマス）に立つと「払う／やめる」の窓。
  所持金が足りなければ払えず、品物を戻すよう言われる。店の床へ置けば商品に戻る。未払いのまま使った・壺に入れて消えた・
  盗まれた品の代金は `g.shopDebt` に残り、一緒に払う。
- **売る**: 店の床（壁より内側）に自分の道具を置くと「店主「〜なら○円で買い取ります」」と「売る／やめる」の窓。
  売った品は買値の商品になる。小銭など値段0の品は買い取らない。
- **泥棒**: 未払いのまま店の部屋（壁の線を含む）の外に出る（歩く・ワープ・吹き飛ばしなど、`updateShop` が毎フレーム判定）と泥棒。
  店主が怒り（`Enemy.Alerted`、倍速）、海老さんの近く（2〜4マス）に番犬が3匹（16階からは猛番犬）現れ、その階の湧き間隔が
  1/3（下限4ターン）になる（`g.shopAlarm`）。未払いの品は自分の物になる。落とし穴・階段で未払いのまま階を去ったとき
  （`leaveShopFloor`）も泥棒として記録する（店主・番犬は前の階に残るので出ない）。店主を倒すと店の品物はすべて自分の物。
  泥棒の回数は `RunStats.ShopThefts`（冒険の記録・中断セーブに入る。記録の一覧に「・泥棒」）、死因は「店主」。
- **店主**（126）: ボスと同じ例外（`IsBoss: true`。ランダム出現・上位種化・即死・吹き飛ばし・場所替え・罠・身代わりの対象外）。
  怒っていなければ `Behavior` で何もしない（攻撃・移動しない）。悪い状態（`statusDefs` の `Bad`）とゾワゾワを受け付けない。
  シフトチェンジの杖でも入れ替わらない。HP400・攻撃50・防御20・経験値1000（第3段階で最も強い深淵海竜 HP184・攻撃44・防御16 より強い）。
  海老さんが攻撃・投擲・杖・自分が起こした罠などで傷つける（`applyDamageToEnemy`・`hitEnemyWithProjectile`）と泥棒と同じ扱い。
  敵の爆発・敵どうしの攻撃・敵が踏んだ罠では傷つかない。
- **番犬**（127 番犬 HP60・攻撃18・防御8、128 猛番犬 HP150・攻撃38・防御14）: 泥棒をしたときだけ現れる1段階の敵。
  ランダム出現の対象外で上位種化しない（`MonsterLevelUpTable` に入れない）。階の深さは 128 で表す。
  **3段階にしない理由**: ボスと同じく出現の経路が1つ（泥棒）だけで、湧きの表・上位種化に乗らないため。
- **表示**: HUD の所持金の下に「未払い：○円」（店が開いているときだけ）、持ち物の名前に「［未払い］」、
  道具・足元の説明に「値段：○円」（商品・未払い）／「売値：○円」（自分の物、店の中だけ）、商品に乗ったときのメッセージに「（○円）」。
  支払い・売却の窓は `draw_shop.go`。ヘルプに「店」のページ。
- **中断セーブ**（すべて省略可能な項目、`saveDataVersion` は3のまま）: 店の部屋は `SavedRoom.Role`、商品・未払いの値段は
  `SavedItem.ShopPrice`、店主が怒っているかは既存の `SavedEnemy.Alerted`、`SaveData.Shop`（`Alarm`・`Debt`）。
  未払いの品の一覧（`g.shopCarried`、ポインタ）は保存せず、読み込み時に持ち物の `ShopPrice` から作り直す。
- **換金の壺**（230）: 仮の売値100を店の売値 `itemSellPrice` に変えた（説明とヘルプも）。
- **BOT**（`bot_shop_test.go`）: 商品を拾いに行かず（`itemGoal`・食料・`worthPicking`）、経路探索で商品のマスを通らない。
  うっかり拾ったら次の行動でその場に置いて返す。怒っていない店主は敵として数えない（隣の敵・近い敵・射線・逃げる先・近づく敵）。
  支払い・売却の窓は X（やめる）で閉じる。売買は wave11。
- **レポート**: `TestSimBatch` の Markdown に「店（性格別、全難易度）」（店のある階に着いた回数・泥棒の回数）を追加。

## 値段の決め方

- 原作（SFC シレン）の価格帯を参考に、種類ごとの相場で決めた（数値は複製していない）。食料 20〜500、回復薬 100〜500、
  悪い薬 50・良い薬 300〜1000、カード 100〜2000（悪いカード 100、強いカード 1500〜2000）、杖 300〜1000＋回数、
  壺 200〜2000＋容量、武器 200〜3000、盾 200〜3000、指輪 300〜3000（呪いの指輪は 300）、矢は1本20。
- 同じ種類の中で効き目が近いものは同じ値段にそろえ、未識別の道具を値段からしぼり込める（原作どおりの楽しみ）。
- 武器・盾は強化値1につき基準の20%を増減（最低は基準の20%）、杖は回数1につき基準の10%（最低50）、壺は容量1につき100、呪いは半額。
- 小銭（0）は売買しない（値段0）。小銭が1回に最大2000円出るので、浅い階でも1〜2品は買える見込み。

## 未決事項（仕様に書かれていないため無難な案で進めたもの）

- **店主の位置**: 指示書の「入口に店主」は、出入口の内側のマスに立たせると唯一の通り道をふさいで出られなくなる（斜めは角を抜けられない）ので、
  内側のマスの壁に沿った隣にした。原作のように未払いのときだけ出口をふさぐ動きは入れていない。
- **店主をボス扱い（`IsBoss: true`）にした**: 例外の扱いをまとめて受けられるため。ボス階には店を作らないので、ボス撃破の判定とは重ならない。
  `TestBossesOnlyAppearOnBossFloors` と `TestRandomIDListsCoverTablesAndExcludeBosses` は店主・番犬を除いて数えるよう直した。
  BOT の `bossAlive`・`isStrongEnemy` は店主もボスとみなすが、ボス階に店が無いので影響しない。
- 店主の強さは階で変えない（敵を階で強くしない方針）。3階では倒せない強さ。泥棒の後の番犬の数（3）・湧き間隔（1/3）も目安。
- 怒っていない店主は、敵の爆発・敵どうしの攻撃・敵が踏んだ罠では傷つかない。海老さんが起こした爆発（自分が踏んだ地雷・投げた道具で作動した罠・爆発の指輪など）は泥棒と同じ扱い。
- 割れた壁（9-B の地形）は店の壁にも出ることがある（地形の担当の規則を変えていない）。壊して外へ出れば泥棒になる。店の床には地形を置かない。
- 店の外へ投げた・置いた未払いの品は未払いのまま（拾い直せる）。中断セーブ→再開すると、その床の品の追跡は消える（拾い直せば再び未払い）。
- 中身入りの壺を売ると、自分の物の中身の売値も足す。未払いの品を入れた壺を売っても、中の未払いの品は商品に戻る扱い（代金は残らない）。
- 未払いの品を換金の壺に入れると、売値は所持金に入り、買値は使った品の代金として残る。
- 出口の支払いの窓は出口のマスに着いたときに1回だけ出す（離れて戻ると再び出す）。払わずに外へ出れば泥棒。
- 商品の説明の値札は説明画面とメッセージだけ（道具の上の値札は30pxの表示では読めないので描かない）。
- 売った・買った回数（`RunStats.ShopBought`・`ShopSold`）も記録する（今は表示しない）。
- wave10-A と同じ `special_rooms.go` を両方で作った。10-A の作業中の版の `RoomRole`・`selectSpecialRoom`・`roomContains` と同じ内容にしてあるので、
  統合時は1つにまとめる（`SavedRoom.Role` も両方で足す見込み）。モンスターハウスと店は `selectSpecialRoom` が役割のある部屋を避けるので重ならない
  （生成の順番は統合時に決める。今は店が地形の直前）。
