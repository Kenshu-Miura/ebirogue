## 変更概要

- にぎり（海老さん20ターン）、暴走（双方15ターン）、身代わり（敵30ターン）、透明（双方30ターン）、無敵（海老さん10ターン）を `statusDefs` の末尾に追加。共通処理による付与・耐性・解除・経過・HUD・中断保存に対応した。
- `main.go` と `game_stub.go` の状態に省略可能な残りターンを追加した。中断データは既存の構造体単位の保存を使い、`saveDataVersion` は3のまま。
- アイテム215〜221を担当別の表 `items_status_special.go` に追加。222〜224は未使用のまま。薬4種と杖3種は既存画像を共用し、杖は5回・未識別・専用の未識別名を持つ。正式名を返す既存の `GetName` の契約は変えず、表示側で未識別名へ切り替える。
- 通常の薬の床出現重みを4、無敵の薬だけ1とした。薬カテゴリ全体の出現割合は変えていない。既存薬同士の相対的な割合も同じ。
- 暴走の攻撃倍率1.5を共通ダメージ式の倍率へ合成。海老さんは最も近い敵へ自動で移動・通常攻撃し、敵なし・移動不可でも足踏みとして1ターン使う。メニュー・射撃・階段確認への入力は暴走が解けるまで受け付けない。`AdvanceTurn` を直接呼ばず、既存の `isActioned` と ActionQueue → `CheckCombatState` の経路を使う。
- 敵AIに標的選択 `specialEnemyTarget` を追加し、身代わり・暴走・透明が共用する。身代わりは動かず攻撃せず、被弾・撃破時の特技と飛び道具の打ち返しも止まる。身代わりを倒しても海老さんに経験値が入らず、倒した敵も上位種化しない（通常の敵どうしの攻撃）。期限後は元の敵として行動する。
- 透明な海老さんは隣接時以外追跡されず、透明な敵はワールド・ミニマップ・軌道予測の対象表示から隠れる。気配察知・透視の指輪があれば見える。海老さん自身は半透明表示。
- 無敵のダメージ阻止を `damagePlayer` に置き、敵・罠・爆発・餓死をまとめて防ぐ。状態異常は従来どおり受ける。
- にぎり中は防御力を0として計算し、敵の命中した攻撃ごとに満腹度を5減らす（0未満にならない）。道具の使用・装備変更・投擲・射撃を拒否し、拾う・置く・説明は可能。にぎりよけの盾はにぎり状態も防ぐ。回復薬の被弾で解除し、困った時のカードの悪い状態の解除にも含まれる。
- にぎりの薬の敵への命中は、ボス以外を経験値なしでウインナーへ変える。ボスには身代わりも無効。無敵の薬は敵には無効。
- BOTは新アイテムの `itemRoles`・`itemValues` を分類し、にぎり・暴走中は足踏み入力にして使えない道具の選択を繰り返さない。新しい戦術の追加は行っていない。
- ヘルプ「特殊な状態」を追加した。`AGENTS.md`、`IMPLEMENTED_FEATURES.md` は編集していない。

## 未決事項（仮決めした仕様）

- 「周囲」の誘引範囲は、身代わりと同室またはチェビシェフ距離8以内とした。複数なら最も近い身代わり、同距離なら敵スライスの先のものを選ぶ。暴走でも身代わりを優先する。
- 暴走中の海老さんは透明・道具擬態で見えない敵を自動行動の標的にしない。敵側も透明な仲間は暴走の標的にしない。既存の睡眠・金縛り・混乱・目潰しの行動制約を優先する。
- にぎり中の「道具・カードを使えない」を優先して、回復薬・困った時のカードの自発使用も拒否する。回復薬は投げ当てられると解除し、困った時のカードの効果そのものはにぎりを解除する。自発使用の例外を設けるかは統合時に決める（仕様の「薬・困った時のカードで治る」との解釈）。
- にぎりの満腹度低下は回避・反射されなかった敵の攻撃に適用し、無敵と重なってHPダメージが0でも満腹度は減る。薬・罠からの状態付与は従来どおり装備能力の無効化のみ／`Shield: true` 指定時のみ盾50%を見る。
- 気配察知に加えて、既存の上位の感知能力である透視の指輪でも透明な敵を表示する。画像は明るいマスだけ、ミニマップは既存の表示範囲に従う。
- 身代わりは適用時に睡眠・金縛りを解除する。他の状態は保ち、期限後はその時点の状態・HPで元の敵に戻る。HPや経験値の定義を上書きしない。
- ウインナー化では敵の持つ盗品を落とし、ウインナーは変化地点から半径4以内の空いた床へ置く。空きがなければ食料だけ消える。撃破時の特技は呼ばない。
- 薬の未識別システムは既存どおり追加せず、未識別名の追加対象は杖3種とした。
