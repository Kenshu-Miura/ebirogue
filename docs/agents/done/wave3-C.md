## 仕様の判断

- 敵・道具ともチェビシェフ距離、同距離はY→Xの順。元の位置が同じ対象はスライスの順を保つ。乱数は使わない。
- 空き床は使用時点の占有を除外して先に確定し、移動で空いた元の位置は追加の集合先として再利用しない。空きが尽きた対象はその場に残る。敵集合ではボスの位置も占有扱いにする。
- 道具寄せは `itemDropFree` に従い、敵のいる床は除外しない（床の道具・罠・階段は除外）。プレイヤーの足元は集合先から除き、そこにある道具は動かさない。
- 困った時のカードは悪い状態異常をすべて解除するが、倍速は維持し、睡眠解除時は HasteOnWake も解除する。空腹回復は原則50、最大満腹度が50未満なら上限に収める（並行担当の悟りの盾との整合・満腹度の不変条件を守るため）。
- `troubleToFix` は Player 全体ではなく状態異常・満腹度・呪いの有無・パワーを引数にする純粋関数とした。スタブの Player に本体専用のフィールドを追加する必要はない。
- カードは既存と同じく Identifiable を実装していない。未識別名・Nの任意名の対象外で、真実の眼で所持品全体を識別してもカード名は変わらない。
