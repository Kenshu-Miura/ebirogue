## 仕様の判断・未決事項

- 数値・確率・出現帯は指示書の値を採用。同出現帯の段2の敵と比べ、ハジキガニ上位種はヨロイエビ上位種と同程度で、明らかな逸脱はない。細かいバランスは統合後に評価する。

- 指示書は体当たりを EnemyAttackMelee に指定する一方、テスト欄には「反射されたら吹き飛ばない」とある。既存の反射は遠距離攻撃専用であり、この近接攻撃には発動しない。選択肢は (1) 近接指定と共通基盤を維持する、(2) 体当たりを遠距離扱いにする、(3) 共通基盤に近接反射の例外を追加する。推奨・今回採用は (1)。回避時にはダメージ・吹き飛ばし・落下がなく、反射の盾だけでは体当たりを防がないことをテストした。
- 不動は移動だけを防ぎ、体当たりのダメージと持ち物落下は残る（指示書どおり）。
- 満腹度を増やす処理は追加していない。
- ゲーム画面上の画像・引き寄せ・体当たり・盾の落下の見た目は開発者に確認をお願いする。画像は作成済み img-2 をそのまま使用し、今回の仮画像や差し替え対象はない。
