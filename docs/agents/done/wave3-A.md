## 仕様の判断

- 呪いの包丁は計画のパワー+1から、指示書で指定された通常攻撃の総攻撃力+3を採用。装備時のパワーを変更せず、各攻撃時の呪い状態を読む。
- 黄金のつるはしは既存つるはし同様に掘削では劣化せず、固有のさび無効を付ける（指示書の※どおり）。
- 大斧は指示書の処理指定を優先し、`CriticalDenominator = min(..., 8)` で1/8。テスト欄の「乱数0〜7で会心、8で非会心」は現行の `rollDamage`（`intn(N) == 0`）と整合しない。実装・テストは8通りのうち0のみ会心とし、問い合わせの上限8も検証した。
- カウンタは攻撃の Execute 内で変える。四ツ叉の発動した必中会心は次の蓄積に数えず0へ戻す。`HitEffects` と命中フックの同じ Execute 内に限り-1を使い、命中フックで0へ戻す（セーブ可能な入力待ちには残らない）。
- 連撃の追撃は通常の命中・会心処理を使用。追撃が実行し終わるまでフラグを保持し、3回目を出さない。元の攻撃で撃破・外れ・敵不在なら追撃しない。
- 木づちは未発見の罠を優先し、なければ道具を1個壊す。損耗はさび止めでも防げない。
- 罠探りの左右は進行方向に垂直な方向（斜め向きも含む）として扱う。
- かつおぶしは強化値-3以下で食べきる。呪われて装備中でもかじれる。口封じではかじれずターンを消費しない。足元メニューには追加しない。
- 火迅の太刀は攻撃開始時に満タン判定を固定し、炎の Action 実行時の敵と地形で射線を求める。前の通常攻撃で正面の敵が倒れた場合は、その後方の最初の敵へ炎が届く。表示は通常攻撃と炎の結果メッセージ。独自の飛翔アニメーションは追加していない。
