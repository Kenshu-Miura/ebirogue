# wave11-0 完了報告: 段11の計測の準備

ブランチ: `agent/wave11-0-measure`（Claude Code が実装し、そのまま master に統合）。指示書は `docs/agents/wave11-0-measure.md`。

## 変更概要

- **expert だけのベースライン** `reports/baseline-expert.json`（各難易度500冒険、git で追跡。`.gitignore` に `!/reports/baseline-expert.json`）。ベースラインとレポートに、計測したコミットとフラグを記録する（`simBaselineFile.Commit`・`Flags`、レポートの冒頭と「ベースラインとの差分」の比較先）。差分の「ベースラインなし」の表示も、指定した `-sim.baseline` のパスを出す。
- **レポートに段7〜10の要素の表を追加**（`sim_wave11_test.go`、性格別・全難易度）。どれもゲームの状態を読むだけ。
  - モンスターハウス（自然生成）: ある階に着いた回数・初めて入った回数・入ったときの HP と所持品の数・滞在ターン・中で死亡。
  - 地形: 地形のある階と無い階の1階あたりの滞在・突風・餓死、割れた壁を壊したマス数、隠し通路を見つけた回数（つながった通路はまとめて見つかるので、1ステップで見つかった分を1回）。
  - 店の売買: 店のある階に着いた・店に入った・買った品・払った額・売った回数・売った額・死亡時の所持金（中央値）。
  - 探索（階段で降りた階）: 階段を見つけてから降りるまでのターン、降りる直前の HP と満腹度。
  - 段8の薬・杖と段9の壺の使い方（expert。expert がいなければ全性格の合計）: ID ごとの手に入れた・使った・投げた・壺に入れた・持ったまま死んだ。
  - 「ベースラインとの差分」に、性格ごとのモンスターハウスでの死亡・地形のある階の滞在・突風・新しい道具を使った回数・店で買った品の変化を追加（ベースラインに無い項目は出さない）。
- **ゲームの統計 `RunStats` に記録用の項目を追加**（`deathcause.go`）: `ThrownIDs`（ID ごとの投げた回数）・`PotInsertIDs`（壺の ID ごとの入れた回数）・`ShopSpent`・`ShopEarned`。どれも省略可能な項目で、古いセーブ・冒険の記録も読める。乱数・判断には触れない。
  - 指示書では「セーブに入らない `Game` のフィールド」としていたが、BOT の計測は冒険の途中で中断セーブ→再開を挟むので、セーブに入る既存の `RunStats` に足した（`UsedIDs` と同じ扱い）。
  - 「手に入れた」はゲームに足さず、BOT 側で所持品の ID ごとの数の増え方から数える。拾うだけを数えると、足元の「交換」や壺から出した品が入らず、使った・持ったまま死んだの方が多くなっていた。
- テスト: `stats_test.go`（投げた回数が ID ごとに数えられ、セーブ・再開後も残る）、`content_pots_test.go`（壺に入れた回数）、`content_shop_test.go`（払った額・売った額）。

## どこで負けているか（11-A/B/C が最初に読む）

### 1. モンスターハウス（11-A）: 死亡の17%

- 自然生成のモンスターハウスのある階に 873 回着き、562 回（64%）入り、**148 回（入った回数の26%）中で死亡**。死亡 884 の17%。難易度別では上級 73・中級 53・初級 22。
- 入ったときの HP は平均89%、所持品は平均19.2個（ほぼ満杯）。滞在は平均34ターン。HP が十分でも、入ると4回に1回倒れている。今の「通路へ下がる」だけでは足りない。
- 中級の目標まで約 +7pt 足りない。中級の死亡 311 のうち 53 がモンスターハウスなので、ここが最も効く見込み。

### 2. 道具（11-B）: 段8・9の道具の多くを使っていない

- **使っているのは倍速・剛力・堅守の薬（205〜207）だけ**で、手に入れた数＝飲んだ数。手に入れてすぐ飲んでいる見込み（ピンチまでとっておいていない）。
- 退化（209）・弱気（208）・透明（216）・にぎり（218）・暴れ（215）の薬、退化・鈍足・弱体・身代わり・暴走の杖（210〜212・219・221）は一度も使っていない（手に入れた 300〜990 個、死亡時に 30〜270 個を持ったまま）。弱気の薬は持ったまま死んだ数が 269 で最多。
- 壺で使っているのは合成の壺だけ（243回入れた）。識別・強化・変化・冷蔵・換金・背中の壺は一度も入れていない。合成の壺は保存の壺と同じ扱いなので、食料などを入れている見込み（合成として使っているかは未確認）。
- **回復薬を持ったまま死亡 76**: 持っていた回復系の道具は無敵の薬 35・完全回復のカード 20 など（同じ冒険で複数を持っていることがある）。無敵の薬（217、`roleHeal`）は一度も飲んでいない。完全回復のカードは持っているのに使う前に倒れている。
- **自分に不利なカードによる被害 49**: 死ぬ直前100ターン以内に使った不利なカードの大半は自爆のカード（41、52回）。expert は自爆のカードを作戦として使う（`bot-tactics.md`）が、HP が半分になった後に倒れている。使う条件の見直しが要る。

### 3. 店（11-C）: 売買0、所持金も少ない

- 店のある階に 1578 回着き、1020 回店に入ったが、買う・売るは0（今の仕様どおり）。
- **死亡時の所持金は中央値0円・上位10%で1736円**。床のお金 2848 のうち拾ったのは 1203（42%）で、BOT はお金を通りがかりにしか拾っていない。買い物をさせるには、まずお金を拾いに行く必要がある。
- **expert が泥棒になった冒険が7回ある**（シード 494・571・581・992〔3〜4階で店主に倒された〕、698〔20階でクリア〕、887〔20階で餓死〕、1186〔上級の19階〕。難易度は `buildSimCases` の割り当てどおり、シード 1〜500 が初級・501〜1000 が中級・1001〜1500 が上級）。商品を拾わない作りなのに泥棒になる経路がある（ワープ・落とし穴・割れた壁・敵に飛ばされるなど）。11-C で原因を調べて直す。

### 4. 地形と探索（11-A・11-C）: 地形は今は大きな負けの原因ではない

- 1階あたりの滞在は地形のある階 234 ターン・無い階 245 ターンで差が無い。餓死は地形のある階 49・無い階 28 で、階の数（12354・6785）で割るとどちらも約0.4%。
- **突風 20 はすべて地形のある階**。割れた壁を壊したマスは 1093、隠し通路を見つけたのは 573 回（あかりのカード・透視の指輪を含む）。突風の冒険を `TestSimReplay` で見て、隠し通路の奥に階段がある型か確かめるとよい。
- 階段を見つけてから降りるまで平均158ターン（1階の滞在の約2/3）。降りる直前の HP は平均96%、満腹度は平均47。HP は戻してから降りているので、11-C の「降りる前の休憩」より「探索の切り上げ」（餓死 77 が死因の1位）の方が効く見込み。
