## ボスの仕様

| ID / 階 | 名前 | 最終HP / 攻撃 / 防御 / 経験値 | 固有行動 |
|---|---|---|---|
| 42 / 10階 | 鉄壁ガニ王 | 110 / 12 / 7 / 300 | 35%で殻か召喚。殻は防御+8、3ターン。手下は既存イシガニ(ID5)、生存中の召喚個体は最大2体、フロアの19体上限を守る |
| 43 / 20階 | 深海ダコ将軍 | 180 / 18 / 8 / 500 | 近接の35%で墨(目潰し3ターン)か二連撃。墨は状態異常耐性盾で防げる。同室・距離2〜5で25%の場所替え |
| 44 / 30階 | 海竜王アカツキ | 210 / 16 / 9 / 800 | 距離2〜6の直線射線で炎か魔法弾(威力18)。HP半分以下で2回行動、鈍足と相殺する |

- 鉄壁ガニ王は同室・距離2〜5でも25%で特殊行動を選ぶ。手下の系統がジェノサイド済みなら召喚しない。
- 全ボスが `IsBoss: true`。ランダム出現・階層別湧き・上位種化の対象外。10/20/30階だけに配置される。
- ボス階では最大面積の部屋をボス用に確保し、プレイヤーは別室から開始する。部屋の連結方法は従来と同じ。
- 殻・召喚・墨・場所替えの副作用はActionのExecute内で実行する。ダメージは既存の計算式・盾防御・死因記録を使う。倒れたボスの予約済み連撃・遠距離攻撃はダメージを発生させない。
- 場所替え後は視界を更新し、移動先の罠を処理する。聖域上のプレイヤーには特殊行動・遠距離攻撃を行わない。
- 殻の残りターンと召喚個体フラグを敵セーブに追加。未収録の旧セーブではゼロ値となる加算的変更なのでバージョン3を維持した。HP・最大HP・防御など既存の保存値は従来どおり復元される。旧仮ボスを含む中断データでは保存時の能力値を維持する。
- HP半減時の行動変化は現在HPから判定するので、再開しても同じ状態になる。
- 撃破時はボス固有名入りのメッセージを追加。階段解放・目標階でのクリアは既存のcheckBossDefeated / clearRunを使う。
- 毒の状態異常・継続ダメージ・パワー低下はボス行動に使用していない。

## 耐性とアイテムの扱い

| 効果 | 10階 | 20階 | 30階 |
|---|---|---|---|
| 睡眠 / 混乱 | 最大3ターン | 最大2ターン | 最大1ターン |
| 金縛り | 有効、攻撃で解除 | 有効、攻撃で解除 | 無効 |
| 封印 / 目潰し / 鈍足 | 有効 | 有効 | 有効 |
| 全滅 / ジェノサイド / 自爆の敵消去 | 無効 | 無効 | 無効 |
| 炸裂装甲のカード | 即死の代わりに威力50の反撃ダメージ | 同左 | 同左 |
| シフトチェンジの杖 | 場所替えとして有効 | 同左 | 同左 |

- シフトチェンジは現行コードでは変身・消去ではなく位置の交換なので、ボス戦を回避しない。有効のまま残した。
- 封印は殻の防御上昇、召喚、墨、二連撃、場所替え、炎・魔法、固有の2回行動を止める。カード由来の倍速は既存仕様を保つ。
- 睡眠・混乱・目潰し中は共通行動が優先される。耐性のターン上限と海竜王の金縛り無効は定数と共通行動入口で管理する。
- ジェノサイドをボスに投げた際の表示も無効化に合わせた。旧セーブにボスのジェノサイドIDがあってもボスは削除しない。

## 不死モードでのボス単体計測

`TestSimBossBalance` を `-sim.immortal` で実行。各ボス・各比較条件につき100シード(1〜100)。仮想キー入力を使うaggressive BOTが実際のゲームループで戦う。

条件はLv14/24/34、最大HP132/182/224、装備込み攻撃8・防御8、パワー8、特殊盾・道具なし。12×12の部屋でボスまで4マスから開始。通常の雑魚・床道具・罠は除外し、10階の召喚手下は含める。仮ボス比較は定義だけを作業開始時のものへ戻す。仮ボスには新ボス固有の耐性・行動を適用しない。

被ダメージは `damagePlayer` に渡された、HP下限適用前の実ダメージ累計。HP1で受けた攻撃も集計し、自然回復と相殺しない。10階は召喚手下の攻撃も含む。撃破ターン数は接近・場所替え・墨の間も含む。

| ボス | 仮ボス 平均撃破ターン / 被ダメージ | 新ボス初回 平均撃破ターン / 被ダメージ | 新ボス最終 平均撃破ターン / 被ダメージ |
|---|---|---|---|
| 10階 | 17.62 / 187.57 | 10.65 / 84.31 | 10.65 / 84.31 |
| 20階 | 24.37 / 318.68 | 12.23 / 78.93 | 13.40 / 113.75 |
| 30階 | 32.73 / 553.09 | 14.52 / 190.23 | 14.52 / 190.23 |

全条件で100/100撃破、違反ゼロ。最終被ダメージは想定最大HPの約64% / 63% / 85%。回復道具・封印・鈍足・防御装備で改善する余地を残した。これは単体の条件を揃えた比較であり、通常冒険の勝率を表すものではない。


## 通常冒険の調整前後比較

指示書の `-sim.runs=300 -sim.difficulty=all` を実行した。6性格×3難易度への均等配分で、実際は各区分17回、合計306冒険になる。

比較前は仮ボス定義、比較後は最終ボス定義。ボス部屋の選択・即時消去の保護など、このブランチの共通部分は両条件で同じにしている。masterそのもの全体との比較ではない。

| 条件 | 冒険 / クリア / 違反 | 10階 到達 / 死亡 / ボス撃破 | 20階 | 30階 |
|---|---|---|---|---|
| 仮ボス | 306 / 0 / 0 | 4 / 4 / 0 | 到達0 | 到達0 |
| 最終ボス | 306 / 0 / 0 | 4 / 4 / 0 | 到達0 | 到達0 |

10階の死亡率100%、撃破率0%は4例だけで、ボス単体の調整には使えない。仮ボスでは1例がボスの投石死、最終ボスではその例が召喚手下のイシガニ死になり、残り3例はライジンシャコ2例・業火イカ1例のまま。20/30階は死亡率・撃破率とも算出不可。

expertの平均到達階は初級4.53・中級5.41・上級5.00で前後同じ。通常冒険の大部分はボスより前で終了するため、能力値は上の単体計測を基準にした。BOT行き詰まり・ソフトロック・panicはいずれも0。
