### 段8-B の特殊系の判断の根拠（`wave8-B.md` の仕様から）

- **身代わり**: 身代わりになった敵は動かず攻撃せず、同じ部屋か8マス以内の敵は海老さんより身代わりを優先して襲う（隣の敵も離れる）。囲まれたときの止める道具として最も効くので、殴り合うと倒れる見積もりのときに使う。ボスには効かないので向けない。
- **にぎり（敵に投げる）**: ボス以外を即座にウインナーにする（経験値は入らない）。倒す道具として扱い、経験値を得られる止める・倒すカードの後に使う。自分で飲むと道具が使えず防御力0なので飲まない。
- **暴走（敵）**: 暴走した敵は一番近い相手を襲い、海老さんと同じ距離なら海老さんを襲う（`specialEnemyTarget`）。攻撃力も1.5倍になるので、隣の敵や1対1では使わず、ほかの敵の方が近い離れた敵にだけ使う。自分で飲む暴れ薬は道具が使えなくなるので飲まない。
- **透明（自分）**: 隣にいない敵に追われなくなる。回復の道具が無く HP が少ないときに、近づいてくる敵から逃げる手段として使う。透明の杖（220）は敵が見えなくなるだけなので使わない（`roleHarmful` のまま）。
- **無敵**: 10ターンすべてのダメージを防ぐ。回復できないときの最後の手段と、HP が半分を切った大きな戦い（倒れる見積もり・ボス・モンスターハウス）で飲む。

### 使わない壺と理由

- **識別の壺**: BOT は今までどおりテンプレート ID で道具を見分けていて、識別しても判断が変わらない（真実の眼のカードを使う条件が変わるだけ）。入れると割るか吸い出しでしか取り出せず、道具を1つ失うのと同じなので入れない。
- **変化の壺**: 同じ種類の別の道具に変わるだけで、得か損かが決まらない。価値の低い道具を入れる案もあるが、壺の中から出せないので入れない。
- **底抜けの壺**: 入れた道具が消えるだけ。割ると周りに罠ができる（敵に投げて罠を作る使い道は効果がはっきりしない）。
- **背中の壺**: 盗み・投げ捨てを中身が引き受ける。今の BOT は盗まれて困る道具の優先度を持っていないので使わない（持っているだけで壺自体が標的になり守りになる）。
- **換金の壺**: 11-C（店）と重なるので入れない（指示書どおり）。

## 未決事項

- `buffpotion`・`statusest`・`strengthpot`・`coolpot` は効果がばらつきの範囲で、上級は切った方がわずかに高い（1.2〜2.4pt）。どの難易度もベースラインより下げないので入れたままにした。11-D でクリア率を合わせるときに改めて測るとよい。
- 合成で残す印は先に入れた順で、価値の低い印（壁掘り・さびない〔価値2以下〕）でも5つの枠が埋まる。後から来た価値の高い印は移らない（強化値だけ移る）。価値の低い予備は入れない、などの絞り込みは入れていない。
- 弱気・退化の薬（208・209）は投げているが、持ったまま死んだ数が 54・61 と多い。強い敵が直線上にいるときだけ投げるため。弱い敵にも投げるかは決めていない。
- 判断ミス死の「自分に不利なカードによる被害」（wave11-0 の未決事項）は、作戦として使う自爆のカードも数えたままにした（集計の定義は変えていない）。
- 換金の壺は 11-C、識別・変化・底抜け・背中の壺は使わない（理由は上の「使わない壺と理由」）。
