# wave2-C: キー設定

## 実装仕様

- `master` の `6df567f` から `agent/wave2-C-key-config` を作成。
- 設定の既存2項目の後に「キー設定」を追加。16の役割と現在の物理キーを一覧表示し、最後に「初期設定に戻す」を配置。
- 一覧の決定で「新しいキーを押してください」に切り替え、次のキーを登録する。既に使用中の物理キーなら2役割の割り当てを交換する。
- 一覧のキャンセルは設定画面へ戻り、メニューキーは設定画面も閉じる。既存のウィンドウ操作に合わせる。
- 物理キーは英字A〜Z、数字0〜9、上下左右、Space、Shift、Tab、Backspace。左右のShiftは共通。Enter、Escape、F1〜F12は登録対象外。論理KeyEnterとKeyF1は固定。
- 画面を開く・登録を開始する・登録する・初期化する際は、キーを離してから次の操作を受け付ける。登録したキーの押下が決定やキャンセルへ漏れない。
- 割り当ては `GameSettings.KeyBindings`（論理キー名→物理キー名）に保存する。既存の `saveSettings` とstorage抽象化を使い、通常プレイだけが永続化する。冒険データやセーブのバージョンは変更しない。
- 旧設定・null・欠けた項目・未知の物理キーは初期値で補完。重複した割り当ては該当項目を初期値へ戻し、その結果生じる衝突も解消する。未知の論理キーは取り込まない。有効な入れ替えは読み込み後も維持する。
- 純粋な検証・補正・入れ替え・表示名の変換はタグなしの `keybinding.go`。Ebiten型と物理入力は `input_ebiten.go` に閉じ込める。
- `Pressed`・`JustPressed`・`PressDuration`の全経路が現在の設定を参照する。入力記録は従来どおり論理キーで記録する。
- ヘルプの操作説明、罠調査・難易度・記録の案内と、各画面に既存のキー案内がある文言を現在の割り当てへ追従させる。方向キーは案内で矢印記号を表示する。
- キー設定の操作はターンを消費しない。ゲームの数値・BOT・乱数・VirtualInput・input_source.goは未変更。共有ファイルの既存行は並べ替えず、設定への項目追加と必要な呼び出し変更に限定。
