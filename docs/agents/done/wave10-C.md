# wave10-C 完了報告：図鑑と発見率

- ブランチ: `agent/wave10-C-encyclopedia`
- 起点: 最新の `origin/master`（`2d6c750`）。master へのコミット・プッシュは行わない。

## 変更概要

- `codex.go` にタグなしの記録形式、旧形式（version 省略）の読み込み、検証、スナップショットの冪等な結合、発見率の計算を実装。
- 通常プレイだけ `ebirogue_codex.json` を storageRead/storageWrite で読み書きする。WASM は同名の localStorage。床・持ち物の表示、拾得、識別、敵の表示・正体の露見・撃破、冒険の死亡原因、罠の発見・踏破を記録する。
- 未表示の壺の中身は発見扱いにしない。以前見た持ち物の識別の変化は追跡する。目潰し中や画面外の敵・床の道具から正体を漏らさない。
- 読み込みエラー・破損・未知の将来バージョンでは警告を表示し、元ファイルを上書きしない。毎ターンは保存せず、階移動・中断/オートセーブ・冒険終了でまとめて保存。
- メニューの「記録」の右に「図鑑」。道具はカテゴリ内 ID 順、敵は系統順・基本種から上位種の順、罠は ID 順。未発見は「？？？」、未識別の道具は名前・説明を隠す。発見済み画像、既存説明、能力値、撃破・敗北数、罠の踏破、各タブ・全体の発見率を表示。
- ↑↓でタブ、←→でページ、X でメニュー、C で全閉じ。案内は keyGuide を使用。長い説明も読めるよう1ページ1件、640×480内で折り返す。
- 対象はテンプレート表から毎回生成し、ボス・今後追加される店主なども自動で含める。現在の表にはデバッグ/BOT専用の除外対象なし。
- 罠の画像分岐だけ共通関数へ抽出し、ゲーム画面と図鑑で共用。ゲームの数値・乱数・ターン処理は変更しない。BOT は既存の「記録」へのメニュー操作を維持する。
- 新規画像・コンテンツ ID・中断セーブ形式の変更なし。AGENTS.md / IMPLEMENTED_FEATURES.md は編集していない。
