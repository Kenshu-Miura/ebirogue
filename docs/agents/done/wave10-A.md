# wave10-A: モンスターハウス

## 変更概要

- ブランチ: `agent/wave10-A-monster-house`。取得した `origin/master`（2d6c750）から作成。
- 4〜9階5%、11階以降8%で最大1部屋を自然生成。1〜3階とボス階は対象外。
- `special_rooms.go` に `RoomRole` と `selectSpecialRoom` を追加。開始位置・階段の部屋と既に役割のある部屋を除く。wave10-B は同じ選択関数を使い、店の役割を追加すること。
- 地形生成後、歩ける床の1/3の敵・1/5の道具・1/20の罠を追加。既存の敵・道具・罠と重ねず、水路などの通行不能地形を避ける。敵は階層別出現表、道具と罠は段9の抽選関数を利用。
- 部屋に元からいた敵も含めて仮眠。初回入室で部屋の全員を起こし「モンスターハウスだ！」を表示。再入室では再表示しない。
- 部屋の `Role` と `Entered` を省略可能な項目として保存・復元。saveDataVersion は3のまま。
- 自然生成とカードの数の決定を純粋関数 `monsterHouseCounts` に共通化。カードの従来の5〜8体・2〜3個と起きた状態での召喚は維持。
- BOT の JSON と Markdown にモンスターハウス内での死亡を追加。判定は死亡時のプレイヤー座標が自然生成の部屋内にあること。
