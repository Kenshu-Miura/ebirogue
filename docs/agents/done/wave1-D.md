# wave1-D 完了報告

## 変更概要

- 新しい冒険の初回起動・死亡後・クリア後に難易度選択画面を表示。上下左右で選択、Zで開始する。
- 前回選んだ難易度だけを GameSettings.LastDifficulty に保存。旧設定・不正な値は上級にフォールバックする。冒険中の難易度は既存の SaveData に保持する。
- 中断データがある起動では選択画面を表示しない。newHeadlessGame は従来どおり引数の難易度で直ちに開始する。
- クリアメッセージ終了後、難易度・到達階・ターン数・レベル・シードを表示し、Zで選択画面へ戻る。結果の保存と中断データの削除は既存の finishRun を利用する。
- HUD の上端に難易度と現在階/目標階を追加。レベル表示の行は変更していない。
- 既存メニュー項目の位置を保ち、4行目に「記録」を追加。保存済みの記録を追加順の逆順で表示し、日時・難易度・結果・到達階・死因を確認できる。上下でスクロール、Xでメニュー、Cで閉じる。空・破損・読み込み失敗の表示も用意した。
- ヘルプの末尾に「難易度とクリア条件」を追加。
- InputSource 経由の入力を使用。BOT のウィンドウ判定とキー操作ヘルパーだけを更新した。
- AGENTS.md、IMPLEMENTED_FEATURES.md、STATUS.md は編集していない。
