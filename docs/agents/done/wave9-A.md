- `maptraps.go`: `pickFloorTrapID(階, intn)`（帯別の重み＋ボス階・30階の落とし穴の除外 `availableTrapIDs`）。床生成とワナのカード（`itemeffects.go`）が使う。`generateMapTrapsWith(…, tuning)` が罠の数に倍率を掛ける（`generateMapTraps` は補正なしの入口）。敵の罠設置・罠増しの指輪は従来どおり一様（`randomMapTrapIDs`）。
- モンスターハウスのカードが増やす道具も今の階・難易度の表を使う（`newRandomFloorItem`）。
- **wave2-A の仮の値を `trap_damage.go` の定数に移し、根拠を書いた**（値は変えていない）: `itemTrapFailRate`（20%、装備はずし・腐敗・散乱の罠）・`scatterTrapMaxItems`（3）・`rottenSausageSatiety`（10）。パワー1減少は既存の `poisonPowerDrain`。
- 床の抽選の乱数はフロア生成の乱数（`newFloorRNG`）のまま。
- BOT のレポート: 「床の道具（各階の到着時、種類別）」の下に **「床の道具（階の帯別、到着時の割合）」** の表を追加（`simOutcome.FloorBandItemKinds`、`renderFloorBandItemKinds`）。

## つまみの一覧と使い方（wave11 向け）

すべて `item_floor_tables.go`。値を変えたら `go test ./...`（表の健全性のテスト）と `TestSimBatch` を回す。

| つまみ | 場所 | 意味 | 初期値 |
|---|---|---|---|
| カテゴリの帯別の重み | `itemCategoryBandWeights` | 帯ごとのカテゴリの割合（同じ帯の合計に対する比）。例: 深い帯の食料を増やすなら `"Food"` の右の列を上げる | 全帯で導入前と同じ |
| 道具ごとの規則 | `itemFloorRules` | `From`/`Until` で出る階、`Weight` でカテゴリ内の重み、`Strong`/`Heal` で難易度の倍率の対象 | 上記 |
| 罠の帯別の重み | `trapBandWeights` | 帯ごとの罠の割合。0 の帯には出ない | 上の表 |
| 食料・回復薬の倍率 | `difficultySpawnTunings[難易度].FoodHealWeight` | 食料のカテゴリの重みと、回復薬（`Heal`: ミンティア・すごいミンティア・大粒ミンティア）のカテゴリ内の重みに掛ける | 1.0 |
| 強い道具の倍率 | `….StrongItemWeight` | `Strong` の道具のカテゴリ内の重みに掛ける（0 より大きければ重みは最低1残る。出さないなら規則の `From` を使う） | 1.0 |
| 1階あたりの道具の数 | `….ItemCount` | `floorItemBaseCount`（10）に掛けて四捨五入 | 1.0 |
| 罠の数 | `….TrapCount` | 抽選した罠の数（5〜10）に掛けて四捨五入 | 1.0 |

- 例: 上級だけ食料を2割増やすなら `DifficultyAdvanced: {FoodHealWeight: 1.2, …}`。初級の罠を減らすなら `TrapCount: 0.8`。
- 補正を入れたら `TestDifficultySpawnTuningNeutral`（全部 1.0 であることを確かめるテスト）を直す。
- 確認はレポートの「床の道具（階の帯別、到着時の割合）」と「食料と滞在」・餓死の数。
- 店（wave10-B）は `pickFloorItemID(g.Floor, g.difficulty, g.randIntn)` で品物を選べる（床と同じ表・補正）。店だけ別の割合にしたいなら、同じ形の表を足して `pickFloorSpawnID` に渡す。

## 未決事項

1. **強い武具を深い階からにしなかった**（上の比較のとおり、遅らせると中級のクリア率が ±5pt を外れた）。原作のように強い武具を深い階からにするかは、wave11 で BOT の強化と合わせて開発者が決める。`Strong` の印は付けてあるので、`From` を入れるか `StrongItemWeight` で増減できる。
2. 指示書の「強化値の高い武具」は、生成時の強化値（-1〜3 の抽選）ではなく基礎の攻撃力・防御力が高い武具と解釈した。階によって強化値の抽選を変える仕組みは作っていない。
3. あかり・真空斬りのカードの重みを2にした根拠は「浅い階から役に立つ基本のカード」という判断だけ（BOT はあかりを特別に使わない）。
4. カテゴリの帯別の重みは全帯で導入前と同じにした（指示書の「今の割合から大きく変えない」）。深い帯の食料などは wave11 で決める。
5. 食料・回復薬の倍率は食料のカテゴリ全体に掛かるので、腐ったウインナー（床にも出る）も一緒に増減する。回復薬はミンティア3種だけで、完全回復のカードは含めていない。
6. 敵の罠設置（`randomMapTrapIDs` の一様抽選）と罠増しの指輪は帯別の重みを使わず従来どおり。
7. `GenerateRandomMap` は補正なし（上級）の入口として残した。テストで難易度を変えたいときは `GenerateRandomMapFor` を使う。
8. 導入後は乱数の対応（重みが100倍になる）が変わるので、同じシードでも個々の冒険は導入前と別物になる。ベースラインは統合時に取り直す。
