## 変更概要

### 1. モンスターハウス（`bot_house_test.go`、`botFeature` は `house`）

人に見える情報だけで判断する。`Room.Role` と、まだ入っていない部屋の敵の配置は読まない。

- **気づき方**: メッセージ履歴に「モンスターハウスだ！」が出た（`newMessages`。履歴は100件で古いものが消えるので、最後に読んだ文で位置を合わせる）か、今いる部屋に起きている敵が5体以上見えたとき、その部屋をこの階のモンスターハウスとして覚える（`updateHouse`）。ボス階では数えない（ボスが呼んだ手下で部屋が混むため）。
- **部屋の敵をまとめて片づける**: 部屋の中にいて、部屋の起きている敵が3体以上で、殴り合ったときの被ダメージの見込み（`fightDamageEstimate`）が HP の50%以上なら、全滅のカード → （4体以上なら）真空斬り・混乱・目潰し・睡眠のカードの順に使う。`itemRoles` の分類は足していない（全滅・真空斬りは攻撃、混乱・目潰し・睡眠は逃走の分類のまま、使う場面だけ足した）。
- **階段**: 階段が8歩以内にあり、起きている敵が先に届かなければ向かう。モンスターハウスの敵が3体以上残っていれば、階段の上で降りる（`expertWantsToDescend` から `houseWantsToDescend`）。降りる前の HP の条件は付けていない（11-C と合わせるため）。
- **通路の入口で1対1**: 今の「通路へ下がる」と同じ仕組み（`pathStepWithin(isChoke, …)`）で、ふだん（5歩・隣に敵がいれば2歩）より遠く（10歩・3歩）まで下がり、入口で長く（24ターン）待つ。下がる先が無く隣に2体以上いれば、ゾワゾワ → 全滅・真空斬り → 動きを止める道具（`expertEscape`）を使い、隣から攻撃できるマスの少ない場所（部屋の隅）へ寄る。
- **HP が危ないとき**（50%未満で隣に敵、ほかにも敵）は、隣の敵の動きを止める道具（金縛り・睡眠・混乱・目潰しのカード、状態異常の薬を投げる）を使う。ワープの道具はこのゲームに無い。
- **眠らせた後**: 部屋に眠っている（動けない）敵が3体以上残っていて部屋の中にいるときは、隣の眠った敵を殴って起こさず（カードで眠らせた敵は起きると倍速）、階段へ向かうか部屋の外へ出る（`expertHouseSneak`）。部屋の外では、その部屋の敵を自分から追わない。
  - 以前は「睡眠のカードで眠らせる → 隣の眠った敵を順に殴る → 起きた敵が倍速で囲む」で倒れていた（シード10など）。
- **部屋の道具**は、部屋に敵が残っている間（眠っている敵を含む）は拾いに行かない（`houseItemBlocked`）。

### 2. 地形（`bot_terrain_test.go`）

- **割れた壁**（`crackedwall`）: 見えている割れた壁（`Tile.Visited`）を、壊す手数を足したマス（通常のマスの3倍）として経路に入れる（`pathStepWeighted`。手数の少ない順に広げる最短経路）。遠回りになるなら、`move` が正面の割れた壁を通常攻撃で壊す。縦横だけ（斜めには壊さない）。外周と**店の部屋の壁（`roomContainsWithWalls(店)`）の割れた壁は壊さない**。経路に入れてよい割れた壁が無い階は、今までの幅優先探索のまま（同じ結果になる）。
- **隠し通路**（`hiddensearch`）: 行き先が無いとき（部屋と通路を見尽くし、敵・罠を越えても階段・未探索へ行けない）だけ、通路の行き止まりと部屋の壁ぎわで正面を調べる（通常攻撃。1回で50%）。1巡で同じ場所を2回、どこも調べ終えたらもう1巡、1階あたり40回まで。あかりのカードは今までどおり手に入れてすぐ使う（強化の分類）。
  - **マップ生成は隠し通路が無くても全部屋がつながるように作る**（`generateTerrain` は元の通路を消さず、水路も連結を確かめて置く）ので、隠し通路の奥に階段がある型は起きない。実際この改善はほとんど発動しない（切っても1500冒険のクリア数が同じ）。
- **水路**: 今までどおり通れないマスとして避ける。向こう岸の道具は経路が無ければ目標にならない。ただし、**追う敵は、まっすぐの距離ではなく歩いて届く距離（12歩以内に隣へ行けるか）で選ぶ**ようにした（`enemypath`、`worthChasing`。詰めて倒しに行く遠距離攻撃の敵も同じ。ボス戦は今までどおり）。水路の向こうの敵へ向かう1歩と、道具・ほかの敵へ向かう1歩が入れ替わり、同じ2マスを何百ターンも往復していたため（シード178・648）。

## ゲームの変更（開発者の決定、2026-10-21）

調査で見つけた2点を開発者に確認した。

1. **道具寄せのカードで商品を店の外へ出したら、その時点で泥棒になり、値段は消える**（変更）。以前は商品が値段の付いたまま店の外の床に残り、店主は未払いにも盗品にもしなかった（`refreshShopLedger` は持ったことのある品しか追わない）ので、拾うと店の外ですぐ泥棒になり、踏まない BOT は動けなくなっていた。
   - `card_effects_wave3.go` の `gatherItemsCard` が集めた後に `g.stealGatheredShopGoods()` を呼ぶ。店の部屋の床（`inShopInterior`）の外にある値段付きの品（床の壺の中身を含む）の値段を0にし、1つでもあれば `becomeShopThief(false)`（店主が怒る・番犬・湧きやすくなる。商売中の店でなければ値段を消すだけ）。店の中で使って商品が店の中にとどまれば泥棒にならない。乱数の使い方は変えていない。
   - ヘルプの「店」のページに「道具寄せで商品を店の外へ出しても泥棒。」を足した（`shop.go`）。
   - テストは `content_shop_test.go` の `TestGatherCardOutsideShopIsTheft`（店の外で使うと泥棒・値段が消える、店の中で使えば泥棒にならない）。
   - BOT は今までどおり、商売中の店がある階では道具寄せのカードを使わない（`gathershop`。使うと泥棒になるため）。
   - 全性格の `TestSimBatch -sim.runs=300 -sim.difficulty=all`（306冒険）は変更の前後で同じ（クリア 28、違反・ソフトロック・panic・BOT 行き詰まり 0、泥棒 0）。上の expert の1500冒険の計測はこの変更の前に測った（expert はこのカードを店のある階で使わないので、結果は変わらない見込み）。
2. **矢が狙った敵を外れて、後ろの店主に当たると泥棒になる**のは仕様どおり（変更なし）。シード577の中級5階などで BOT が泥棒になっていた型。BOT の射撃は「直線上で最初に当たる敵が店主でない」ことだけを見ているので、避けたければ 11-C で「店主が同じ直線上にいれば撃たない・投げない」を入れるとよい。
