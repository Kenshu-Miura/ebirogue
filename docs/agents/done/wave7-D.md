# wave7-D: 仮画像の差し替え

ブランチ: `agent/wave7-D-images`。作業元: 最新 master `b3224c9`。
ゲームコード、AGENTS.md、IMPLEMENTED_FEATURES.mdは変更していない。

## 変更概要

- 画像生成原画から罠10枚、食料1枚、ボス3枚を作成。同名の30x30 RGBA PNGへ置換。
- 既存画像12枚を確認し、左上光源・暗色輪郭・鮮やかな陰影に合わせた。
- [差し替え前](wave7-D-before.png)と[差し替え後](wave7-D-sheet.png)に、暗い床2種類上で4倍表示。第3段階21 IDを基本種・第2段階と比較した（ID61/62は同じ画像）。
- 原画はコミットしない。プロンプトは `tools/wave7-prompts.md`、加工は `tools/process_wave7_images.py`（既存加工器を再利用）、シートは `tools/wave7_sheet.py`。
- 旧ボス・ダメージ罠・所持品罠の生成スクリプトには「正式な画像に差し替え済み。再実行しない」を表示して終了するガードを追加。

## 差し替え一覧

- 移動罠: `warp_trap.png`、`pitfall_trap.png`、`bear_trap.png`。
- ダメージ罠: `wood_arrow_trap.png`、`iron_arrow_trap.png`、`falling_rock_trap.png`、`large_mine_trap.png`。
- 所持品罠: `unequip_trap.png`、`spoil_trap.png`、`scatter_trap.png`。
- 食料: `rotten_sausage.png`（カビ・緑斑・ハエ）。
- ボス: `boss_crab.png`（冠と重装甲）、`boss_octopus.png`（金の兜と紫の触手）、`boss_dragon.png`（赤金の体と冠）。
- 第3段階: `onryou_gani.png`、`jikuu_kurage.png`。比較前に前者は基本種と赤紫が近く、後者は基本種とほぼ同じ青になっていたため列挙して選定。第2段階からの色相回転を+150°から+60°に変更。アルファ・輪郭は完全一致、HSL明度は丸め差1/255以内を確認。

## 未決事項

- 描き直し対象の数・色相角は仕様で固定されていないため、上記2種だけ+60°へ変更した。
- 罠は既存の毒矢の罠に合わせた石板、ボスは通常種と異なる冠・装甲のシルエットを採用。
- 開発者による実機での30px表示、罠の発見済み表示・ミニマップ、ボス戦中の視認性確認は残る。
- 加工器は生成atlasの実際の配置を切り抜き座標として固定し、原画のサイズが異なる場合は停止する。
