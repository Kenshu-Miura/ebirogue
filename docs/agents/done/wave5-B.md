## 仕様の判断

- 能力値・出現帯・重み・30%の特殊攻撃・20%の分裂・15%の痛恨は指示書どおり。同じ帯の既存敵に比べ、直ちに修正すべき数値の逸脱はない。
- サビヒトデのさび対象は実行時の装備から rollRustTarget で抽選。武器・盾が両方無い場合は共通の通常攻撃へ戻す。
- 分身は共通処理どおり被弾後のHPを引き継ぎ、状態異常・持ち物を引き継がず、経験値0。分身がさらに分裂しても経験値0を設定する。
- 投げ捨ては未装備の杖を優先し、無ければ他の未装備品を選ぶ。貼りついた聖域は共通処理で除外する。耐性で防いだ場合は防御メッセージを出し、対象無しの文言を重ねない。投げ捨て後も逃走しない。
- 満腹度を増やす処理は追加していない。
- wave5-C は未統合のため、いたずらよけの盾そのものとの組合せは統合時に確認する。このブランチでは StatusItemToss を防ぐテスト用指輪で共通耐性経路を確認した。
