# wave2-A: 装備・所持品の罠 完了報告

ブランチ: `agent/wave2-A-item-traps`。基点: master `5c88a20`（origin/master と一致を確認）。

## 変更概要

- 罠ID 12 装備はずしの罠、13 腐敗の罠、14 散乱の罠、アイテムID 71 腐ったウインナーを追加。既存のテンプレートと床・ワナのカードの重み付き抽選一覧を並べ替えず末尾へ追記した。敵の罠設置の一様抽選にも含まれる。
- 効果は `maptraps_items.go`、腐った食料の使用は `itemeffects_rotten_food.go` に分離。重複なしの対象選択はタグなしの `item_trap_selection.go` に分離し、純粋関数のテストを両ビルドで実行する。ゲーム中の乱数はすべて `g.randIntn` を通す。
- 装備はずしは武器・盾の装備中の候補から1つ選び、既存の `UnequipItem` を通して能力値と特殊盾の効果を解除する。**ユーザーの最新指定に従い、呪われていても外し、所持品に残す。床に落とさない。呪い自体は解除しない。** 矢・アクセサリは外さない。対象がなければ何も変えない。
- 腐敗は所持品直下の未腐敗の食料1つを腐ったウインナーへ置き換える。壺の中身・既に腐った食料は対象外。対象がなければ何も変えない。
- 散乱は全装備スロットの装備中の物を除外し、未装備の所持品を最大3個、周囲8マスの空き床へ置く。壁・階段・既存のアイテム・罠・敵を避け、同じ床へ重ねない。置ける床の数までしか選ばず、置き場所がなければ所持品を保持する。壺は同じオブジェクトを中身ごと移動。聖域のカードは通常の「置く」と同じく貼り付き、既に貼り付いたカードは移動しない。
- 腐ったウインナーは満腹度10回復（最大値まで）、毒8ターン。既存の毒が長ければ短縮しない。満腹時の最大満腹度増加はなく、盾の状態異常耐性判定は行わない。回復・毒・消費は Action の Execute で実行し、所持品と足元の両方から食べられる。
- 3罠の不発率は20%。すべての副作用を Action の Execute へ置く。表示・画像読み込み・ヘルプを追加し、ミニマップには既存の発見済み罠共通表示を使う。
- 既存の明示IDによる罠復元・食料復元・壺の再帰保存・聖域の貼り付き保存・装備スロット保存・乱数状態保存を利用し、保存形式とバージョンは変更しない。
- 腐敗の効果は `init` でテンプレートに登録する。ワナのカード→罠テーブル→食料生成→アイテムテーブルの初期化循環を避けるためで、IDは通常どおりテーブルに含まれ抽選一覧にも含まれる。
- `AGENTS.md` と `IMPLEMENTED_FEATURES.md` は編集していない。

## 未決事項・統合上の注意

- 仕様未指定の数値は最大散乱数3・腐った食料の回復10と毒8ターン・罠の不発率20%とした。階層別の出現率と数値の最終調整は今後のバランス作業で行う。
- 腐ったウインナーも既存の床アイテム抽選対象に含まれる。通常の Food として BOT が食べられる。専用のBOT戦略調整は行っていない。
- 装備はずしの最終仕様は指示書の「呪われた装備は外れない」「足元に落とす」からユーザーが変更したため、統合時にも本報告の仕様を採用する。
- 足元への再配置・自動拾得・罠の連鎖・壺の破壊は追加しない。散乱は隣接床を使用し、敵のいる床も避ける。
- 他担当も `main.go`、`draw.go`、`help.go` を変更するため、統合時は両方の追記を保持し、ヘルプページ数のテストも統合後の数に合わせる。
