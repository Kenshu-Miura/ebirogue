## 変更概要

- アイテム225〜232の8種類の壺を専用テーブルで追加。233〜239は未使用の予備。
- 合成の壺は最初の同カテゴリの武器・盾を土台とし、能力を重複なし・土台込み5印まで移す。強化値は負の値も含めて加算し、呪いは論理和。同じIDの杖だけ使用回数を合算する。土台の基本攻撃力・防御力・テンプレート・蓄積カウンターは維持する。
- 合成した能力は既存の `Abilities` で動作。セーブはテンプレートとの差分を省略可能な `SavedItem.ExtraAbilities` に記録し、壺の中・所持品・敵の盗品にも既存の再帰変換で対応。saveDataVersionは3のまま。
- 識別・強化・同カテゴリ変化・底抜け消失・換金を入れるActionのExecuteで適用する。変化はID順の候補から冒険の乱数源で抽選する。
- 背中の壺は盗む共通処理と投げ捨てる共通処理で優先標的となる。中身を失った後も壺は残り、空の壺は壺自体が標的。盗難・投げ捨て耐性を優先する。
- 冷蔵の壺は既存の「壺の中身は腐敗対象外」の経路を再利用し、食料を保護して自由に取り出せる。
- 新壺も容量3〜5、壺拡大・吸い出し、割ったときの散乱、セーブに対応。底抜けだけは割れた場所と周囲の空き床に発見済みの罠を作る。
- 武器・盾の説明に日本語の印一覧を表示し、説明文を30文字で折り返す。所持品・足元の説明窓は行数に応じて高さを増やす。
- 未識別の色名・壺8点の仮画像・ヘルプを追加。画像はIDで選び、既存のPotカテゴリを使う。
- BOTのitemValuesへ最低限の価値を登録し、合成の壺を保存の壺と同じ予備食料収納先として扱う。

## 未決事項（仕様にないため採用した案）

- 換金価格表はまだ無いため全カテゴリ1個100の仮売値。wave10-Bで価格表へ接続する。
- 合成・背中は保存と同じく直接取り出せる。識別・強化・変化は割るか吸い出しで取り出す。強化の壺への出し入れだけで無限強化できないようにした。
- 容量は従来どおり現在の中身の個数で判定。合成で減った枠は再利用でき、底抜け・換金に消費回数制限は設けない。満杯の合成壺には合成可能な道具も入れられない。
- 変化先がないカテゴリ（お金・矢など）は元の道具を保持する。変化時には強化値・呪い等を新たに抽選する。
- 底抜けの壺は着地点を含む周囲9マスのうち、通常の道具を落とせる床・通路に既存罠を一様抽選して作る。既存の罠や道具には重ねない。
- 複数の背中の壺がある場合は所持品順の最初の壺、内容物は先頭を対象にする。所持金の盗難は背中の壺の対象外。
- 冷蔵以外の壺の中身も既存仕様で腐らないため、その保護は維持した。現在敵に食料を腐らせる処理はなく、食料化（にぎりエビ）は腐敗ではないため標的変更しない。
- 壺自体の識別状態は従来の識別手段で変える。入れる効果だけでは壺の識別を自動更新しない。
- バランス調整、合成の積極利用などBOT強化はwave11へ残す。
