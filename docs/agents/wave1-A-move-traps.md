# wave1-A: 移動に干渉する罠（Codex 用）

ブランチ: `agent/wave1-A-move-traps`
前提: フェーズ0（`docs/agents/phase0-foundation.md`）が main にマージ済みであること。
最初に `AGENTS.md` と `docs/agents/README.md` を読み、並列作業のルールに従うこと（`AGENTS.md` と `IMPLEMENTED_FEATURES.md` は編集しない）。

## 作るもの

| 罠 ID | 名前 | 効果 |
|---|---|---|
| 5 | ワープの罠 | プレイヤーを同じフロアのランダムな床へ移動させる |
| 6 | 落とし穴 | 小ダメージを受けて次の階へ落ちる |
| 7 | トラバサミ | 一定ターン移動できなくなる（攻撃・道具の使用はできる） |

## 仕様

- 罠の追加手順は `AGENTS.md` の「新要素追加チェックリスト」に従う（テーブル、効果、画像、セーブ、テスト、ヘルプ）。
- 乱数はすべて `g.rng` 経由にする。ワープ先と落下ダメージは、乱数を注入できる純粋関数に切り出してテストする。
- **落とし穴はボス階（10・20・30階）に生成しない。** 30階より下へ落ちる経路を作らない。落下先がボス階になるのは構わない。
- 落とし穴での移動は、階段での移動と同じオートセーブ・フロア初期化の経路を通す（処理を手書きで複製しない）。
- トラバサミの残りターンは `StatusAilments` に追加し、`game_stub.go` の定義にも同じフィールドを追加する。セーブ対象にする。
  移動しようとしたときは「トラバサミにかかっていて動けない」と表示し、ターンを消費しない。
- 落とし穴による落下ダメージで死亡したときの死因（`lastDamageSource`）を記録する。
- 敵が罠を踏む処理は wave2 で追加する。効果関数は、将来「対象が敵の場合」を追加しやすい形にしておく。
- 新しい罠の画像は、30x30 の透過 PNG をスクリプトで仮作成してよい。仮画像は完了報告に列挙する。
