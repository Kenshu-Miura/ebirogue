## 作るもの

1. **敵が罠を踏む**: 敵が罠のマスへ移動したとき（歩く・吹き飛ばし・引き寄せ・ワープで着地）に作動する。
   - 踏まない敵: 浮遊の属性（`EnemyTrait`）、罠を仕掛ける敵（ワナシヤドカリ系）、ボス、壁の中の敵、道具・階段に化けて動いていない敵。
   - 不発率は海老さんと同じ。見えている場所で作動した罠は発見済みになる。
   - 罠ごとの敵への効果を `mapTrapTemplate` に項目（例 `EnemyEffect func(g *Game, enemyIndex int)`）で持たせる。目安: 睡眠ガス・鈍足・トラバサミ → 同じ状態（wave7-A の `applyEnemyStatus`）、ダメージ罠・地雷 → 同じ威力のダメージ（`applyDamageToEnemy`）、ワープ → 同じ階の空き床へ、落とし穴 → その敵がフロアから消える（経験値なし）、毒矢 → ダメージ＋攻撃力の低下（wave8-A が先に統合されていればその状態、まだなら ダメージのみ）、サビ・装備はずし・腐敗・散乱・回復封じ → 効果なし（踏んでも消費しない）。
   - 罠で倒れた敵の経験値は海老さんに入らない（作動させたのが海老さんの矢・投擲・爆発なら入る）。`OnDefeated` は呼ぶ。
2. **矢・投げた道具で作動**: 飛んでいる道具・矢が床の罠のマスに**着地した**とき作動させる（飛び越えるだけでは作動しない）。効果は「そのマスにいる者」に及ぶ（誰もいなければ空振り。地雷・大型地雷は周囲に効く）。罠は発見済みになる。杖の魔法弾は作動させない。
3. **爆発で作動**: 大型地雷・敵の範囲爆発（`enemy_explosion.go`）・爆発の指輪の範囲内にある地雷系の罠は誘爆する（連鎖は1回の爆発につき深さ3まで）。ほかの罠は爆発で消える。
4. 海老さんが罠を「攻略に利用できる」ことをヘルプの罠のページに1行で書く。

## 守ること

- 罠の作動は Action の `Execute` の中で行い、敵の移動ループ中にスライスを壊さない（敵が消える・ワープする場合は、`MoveEnemies` の後でまとめて処理するか、既存の削除のパターンに合わせる）。
- 乱数は `g.randIntn` など Game の乱数源を使う。
- 罠の効果関数が海老さんを前提にしている箇所（`g.steppedTrapSource` など）は、対象が敵のときに海老さんへ効かないことをテストで確かめる。
