# wave10-B: 店・売買・店主・泥棒（Claude Code 用）

ブランチ: `agent/wave10-B-shop`
前提: **段9が master に統合されていること**（品ぞろえに wave9-A の階層別の抽選関数を使う）。`AGENTS.md`、`docs/agents/README.md`、`docs/agents/feature-completion-plan.md`、`docs/agents/wave10-A-monster-house.md` の「特別な部屋」の段落を先に読む（`special_rooms.go` を 10-A と共有する）。
ID: 敵 126（店主）、127〜128（番犬。泥棒をしたときに現れる。3段階にしないボスと同じ例外扱いにするか、理由を完了報告に書く）。

## 作るもの

1. **値段表**（タグなしの純粋なファイル、例 `item_prices.go`）: すべてのアイテムテンプレートに買値・売値（目安: 売値＝買値の半分）。強化値・杖の回数・壺の容量・呪いで値が変わる。値段で未識別の道具の種類を推測できるのは原作どおりの楽しみとして残す。**値段の無いテンプレートがあるとテストが落ちる**ようにする（今後の追加の漏れを防ぐ）。
2. **店の部屋**: フロア生成時に確率（目安 3階から 10%。ボス階・モンスターハウスと同じ部屋にはしない）で1部屋を店にする。床に商品（wave9-A の抽選関数、5〜12個）、入口に店主。
3. **買う**: 商品を拾うと「代金未払い」になる。店主に話しかける（隣で `Z`）か、店の出口で「支払う」選択肢を出す。所持金が足りなければ置いていく。
4. **売る**: 店の床に自分の道具を置くと店主が値段を言い、売る／やめるを選ぶ。
5. **泥棒**: 未払いのまま店の部屋から出る（歩く・ワープ・落とし穴・階段）と泥棒になる。店主が敵になり（強い。目安: その階の第3段階の敵より強い）、番犬が出て、その階では敵が湧きやすくなる。店主を倒すと商品は自分の物になる。泥棒の状態は冒険の記録に残す（死因「店主」など）。
6. 店主は普通の敵ではない（攻撃しない・動かない・罠を踏まない・状態異常・吹き飛ばし・場所替えを受けない）。こちらから攻撃・投擲・杖を当てると泥棒と同じ扱いにする。
7. 中断セーブ: 店の部屋・商品の値段・未払い・泥棒の状態を保存（省略可能な項目）。
8. 所持金の使い道ができるので、HUD の所持金の表示と、店の中の値札の表示（道具の上か説明画面）を作る。店主の仮画像を作る。
9. BOT: 商品を拾わない（店の床の道具を拾う対象から外す）。売買は wave11 で考える。泥棒しないことをテストで確かめる。

## 守ること

- 店主・番犬の挙動は `enemy_behaviors.go` の `Behavior` を使う。`enemy_ai.go` の共通処理を大きく変えない。
- 乱数はフロア生成なら `newFloorRNG`、冒険中は `g.randIntn`。
