# wave11-B: BOT の道具の使い方（段8の薬・杖と段9の壺）

前提: wave11-0 の統合後。11-A・11-C と並列に進める。

最初に `AGENTS.md`、`docs/agents/README.md`、`docs/agents/STATUS.md`、`docs/agents/feature-completion-plan.md`（「段11」）、`docs/agents/done/wave11-0.md`（新しい道具の使われ方）、`docs/agents/done/wave8-A.md`・`wave8-B.md`・`wave9-C.md`、`docs/agents/done/bot-tactics.md` を読むこと。

## 背景

段8・9の担当は、BOT が新しい道具で行き詰まらないための最低限の分類（`itemRoles`・`itemValues`）だけを入れた。たとえば expert は無敵の薬（217、`roleHeal`）を飲まないので、持ったまま死ぬと「回復薬を持ったまま死亡」に数えられる。合成の壺は保存の壺と同じ扱いで、合成も識別もしない。

## やること（主に `bot_expert_items_test.go`。分類表は `bot_expert_test.go` の `itemRoles`）

道具の正体の扱いは今の BOT と同じにする（新しく人に見えない情報を読まない）。

### 1. 薬・杖（205〜221。表は `items_status_stats.go`・`items_status_special.go`）

- **自分に飲む強化**: 倍速（205）・剛力（206）・堅守（207）・無敵（217）などは、「殴り合うと倒れる見積もり」（今の `expert` の判断）になったとき、ボス戦の開始、モンスターハウスで囲まれたときに飲む。無敵の薬は回復薬が無いときの最後の手段にも使う。
- **敵に使う弱体**: 鈍足（210）・弱体（211）・退化（212）の杖、弱気（208）・退化（209）の薬を投げるのは、一撃で倒せない強い敵（第3段階・ボス〔効かない状態は `bossStatusImmunities`〕）に向けて。退化は基本種・ボスに効かないので振らない。
- **不利な道具**: 加速の杖（213）など自分に不利なものは使わない（今の `roleBad`）。敵に投げて意味があるものだけ投げる。
- 段8-B の特殊系（にぎり・暴走・身代わり・透明・無敵）は、それぞれ「いつ使うと得か」を `docs/agents/done/wave8-B.md` の仕様から決め、判断の根拠を完了報告に書く。

### 2. 壺（225〜232。合成・識別・強化・変化・底抜け・換金・背中・冷蔵。処理は `pots_synthesis.go` など）

- **合成の壺**: 装備中の武器・盾を土台にして、印（能力）の付いた予備の武器・盾を入れて合成する。どの印を残したいかは今の `itemValues`・`ringValues` の考え方で点数を付ける。
- **強化の壺**: 装備中の武器・盾を入れる。
- **識別の壺**: 正体の分からない道具を入れる（今の BOT が正体をどう扱っているかに合わせ、扱いを変えない範囲で）。
- **冷蔵・保存の壺**: 予備の食料を入れる（今の保存の壺と同じ）。
- **換金の壺**: 11-C（店）の担当と重なるので、ここでは「入れない」でよい。
- 変化・底抜け・背中の壺は、使って得になる場面がはっきりしなければ使わない（理由を完了報告に書く）。

### 3. 計測

- 改善ごとに `botFeature` の名前を付け（例: `buffpotion`・`debuffcane`・`synthesis`）、`-bot.off=<名前>` で個別に切って効果を測る。
- 比較は expert の1500冒険（各難易度500）と `reports/baseline-expert.json`（コマンドは wave11-A の指示書と同じ）。見る数は wave11-0 の「新しい道具の使い方」（使った回数・持ったまま死んだ回数）、判断ミス死、難易度別のクリア率、到着時の平均レベル。

## 守ること

- **ゲームのコード・数値は変えない**。不具合を見つけたら直して `regression_test.go` に回帰テストを足し、完了報告に分けて書く。
- クリア率を目標に合わせにいかない（調整は 11-D）。どの難易度のクリア率もベースラインより下げない（ばらつき約 ±3pt を超えて下がる改善は入れないか、`botFeature` で切ったまま残して報告する）。
- `itemRoles`・`itemValues` の分類を変えたら、その理由をコメントに書く。

## 完了条件

- gofmt、`go test -tags test ./...`、`go test ./...`（`TestSimSmoke` を含む）が成功。新しい判断には小さな盤面のテストを足す（例: 殴り合うと倒れる見積もりで倍速の薬を飲む、合成の壺に予備の武器を入れる）。
- expert 1500冒険で違反・ソフトロック・panic 0、BOT 行き詰まり 0。
- 完了報告は `docs/agents/done/wave11-B.md`（改善ごとの on/off の比較、`botFeature` の名前、AGENTS.md の BOT の説明への追記案、未決事項）。
