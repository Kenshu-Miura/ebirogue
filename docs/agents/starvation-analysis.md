# 餓死の増加の原因調査

調査日: 2026-10-14。対象: 追加計画の段1〜段3を統合した master（`6d6402c`）と、段1の前の共通基盤 F5 の直後（`9e7b9d1`）。
方法: 両方のコードで同じ条件・同じシード（`-sim.runs=1500 -sim.difficulty=all`、1512冒険）を回し、冒険ごとの結果（死因・ターン数・到達階・所持品・食料を拾った数と食べた数・到着した階の床の食料の数）を比べた。ゲームの数値は変えていない。

## 結論

1. **主な原因は、敵に倒される冒険が減って、長く生き延びる冒険が増えたこと。** 追加した武器・盾・指輪で BOT が強くなり、敵などによる死亡は 1220→1149 に減った。そのぶん、食料が足りずに倒れる時点まで生き延びる冒険が増えた（800ターン時点で生きている冒険 753→809、1600ターン時点 320→373）。
2. **もともと食料の収支がぎりぎり**で、遅い BOT（aggressive・cautious・itemUser）は餓死しやすい構造になっている。
   - 床に出る食料は1階あたり約0.55個。食料1個の満腹度の回復は平均約65（ウインナー50・ジャンボ100・天むす最大・腐ったウインナー10 が同じ重み）。
   - 遅い BOT は1階に約300ターンかかり、満腹度は1階あたり約30減る。expert は約170ターン・約17。
   - 餓死した冒険は、到着した階の床にあった食料の半分も拾えていない（拾った数 / 床にあった数 ≒ 0.4。前後で同じ）。
   - 最初の餓死の山は 800〜1200ターン・3階前後。この区間で餓死した冒険の8割は食料を1つも拾っておらず、うち7割はそもそも到着した階に食料が無かった。
3. **原因ではなかったもの**
   - 指輪の出現の重み 1→3（段2）: 食料の割合が約5%下がったが、重みを1に戻しても餓死は 216→214 で変わらない。
   - 食料を失う新しい経路（さび・投げ捨て・持ち物を落とす・盗難）: 餓死した冒険で食料を持ったまま死んだのは1件だけで、食料を拾った数・食べた数も前後でほぼ同じ。
   - 所持品が満杯: 餓死した冒険のうち満杯で終わった割合は 37%→49% に上がったが、冒険全体で満杯で終わる割合は増えていない。長く生き延びた冒険ほど所持品が埋まるという相関で、主因ではない。

## 参考の試し（コミットしていない）

| 変更 | 餓死 | クリア | 床の食料（1階） |
|---|---:|---:|---:|
| なし（段3 統合後） | 216 | 52 | 0.54 |
| 指輪の重み 3→1 | 214 | 57 | 0.57 |
| 食料の重み 4→5（+25%） | 188 | 49 | 0.67 |

食料を25%増やしても餓死は13%しか減らない。BOT が床の食料の半分も拾わないため、出現を増やす効果が薄まる。

## 対応の選択肢（開発者が決める）

1. **何もしない**: 餓死は主に遅い BOT の死に方で、expert の餓死は252冒険中19（7.5%）。満腹度の圧力はシレン系の設計どおりともいえる。人が遊んだときの感触で判断する。
2. **食料の出現を増やす**: 食料の重み 4→5 で餓死 −13%。腐ったウインナーの重みを下げて、カテゴリ内の平均の回復量を上げる方法もある。
3. **序盤に食料を保証する**: 1〜3階のどこかに食料を1個置く。最初の餓死の山（3階前後で食料を1つも見ていない冒険）に直接効く。
4. **BOT の改善**: 遅い BOT が床の食料を拾い残す・同じ階に長くとどまる点を直す。ゲームの数値は変わらず、計測だけが現実に近づく。**→ 2026-10-15 に実施（`done/bot-food.md`）。餓死 231→32。** SFC シレンとの食料の出方の比較は `bot-strategy-research.md` の1。

アイテム・罠の階層別テーブル（STATUS の 5b）と一緒に決めるのが自然。
