## 作るもの

設定ウィンドウから、論理キー（`input_source.go` の `Key`）に割り当てる物理キーを変更できるようにする。

## 仕様

- 論理キーの列挙（`KeyZ` など）は名前を変えない（変更箇所が膨大になるため）。代わりに、論理キーごとの役割名の表を追加する（例: `KeyZ` → 「攻撃・決定」、`KeyX` → 「ダッシュ・キャンセル」、`KeyA` → 「向き変え・射線表示」、`KeyC` → 「メニュー」、`KeyD` → 「矢を撃つ」、`KeySpace` → 「扉を開く」、`KeyShift` → 「斜め移動」、`KeyF`/`KeyS`/`KeyN` → 「絞り込み」「整頓」「名前を付ける」、`KeyH` → 「ヘルプ」、`KeyL` → 「メッセージ履歴」、上下左右 → 「上」「下」「左」「右」）。`KeyEnter` と `KeyF1`（デバッグ）は変更の対象外。
- 割り当ては `GameSettings` に保存する（例: `KeyBindings map[string]string`、論理キー名 → 物理キー名）。冒険データ（`SaveData`）には入れない。
  - 項目が無い旧設定、未知のキー名、同じ物理キーの重複がある場合は、その項目を初期値に戻して読み込む（読み込みは失敗させない）。
  - 初期値は現在の割り当て（`input_ebiten.go` の `ebitenKeys`）と同じ。
- 変更の操作:
  - 設定ウィンドウに「キー設定」を追加し、役割名と現在のキーの一覧画面を開く。
  - 項目を選んで決定すると「新しいキーを押してください」状態になり、次に押された物理キーを割り当てる。
  - 押したキーが別の役割に使われていたら、2つの役割のキーを入れ替える（常に全役割が別々のキーを持つので、決定・キャンセル・移動ができなくなることはない）。
  - 割り当てられる物理キーは英字・数字・矢印・Space・Shift・Tab・Backspace など通常のキーに限る。Enter、Escape、F1〜F12、修飾キーの左右の区別は使わない。
  - 一覧の最後に「初期設定に戻す」を置く。
  - どの操作もターンを消費しない。
- 割り当ての検証・入れ替え・読み込みの補正は、タグなしの純粋関数のファイル（例: `keybinding.go`）にまとめて単体テストする。Ebiten の型は `input_ebiten.go` 側に閉じ込める。
- ヘルプの操作説明（`help.go`）と、画面上でキーを案内している文言（難易度選択・クリア画面・確認画面など。`grep` で「Z：」「Zで」などを探す）は、現在の割り当てのキー名を表示する。
- BOT・テスト・リプレイは論理キーで動くので影響を受けないこと（`VirtualInput` は変更しない）。
