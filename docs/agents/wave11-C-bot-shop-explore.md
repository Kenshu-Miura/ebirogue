# wave11-C: BOT の店の売買と探索の切り上げ

前提: wave11-0 の統合後。11-A・11-B と並列に進める。

最初に `AGENTS.md`、`docs/agents/README.md`、`docs/agents/STATUS.md`、`docs/agents/feature-completion-plan.md`（「段11」）、`docs/agents/done/wave11-0.md`、`docs/agents/done/wave10-B.md`（店の仕様）、`docs/agents/done/bot-food.md`、`docs/agents/starvation-analysis.md` を読むこと。

## 背景

- 今の BOT は店で売買しない（商品を拾わず、経路でも商品のマスを避け、支払い・売却の窓は X で閉じる。`bot_shop_test.go`）。人は店で食料や回復を買い、要らない道具を売る。
- 以前の expert だけの計測で、深く潜るほど餓死と突風（1階あたり約250ターン）が上位に戻った。残った課題は「探索を切り上げる条件」と「降りる前に HP を戻す」（`STATUS.md`）。

## やること

### 1. 店（`bot_shop_test.go`）

- **売る**: 店の床に、`itemValues` の低い道具（予備の重複・不利な道具・使い道の無い壺など）を置いて売る。売値の確認の窓では「売る」を選ぶ。
- **買う**: 所持金で買える商品のうち、今の持ち物の最低の価値より高いもの（優先は食料・回復薬・強い武器・盾）を拾い、店主に話しかけるか出口で払う。所持品が満杯なら先に売る。
- **泥棒をしない**: 払えない商品は店の中に置いて返す（今の「拾ったら置いて返す」を残す）。店から出る前に未払いが0であることを確かめる。割れた壁・ワープ・落とし穴などで店を出る経路を通らない。
- 換金の壺は、店で売るよりも得な場面がはっきりしなければ使わない（理由を完了報告に書く）。
- 泥棒の回数（レポートの既存の項目）が0のままであることをテストとレポートで確かめる。

### 2. 探索の切り上げと降りる前の準備（`bot_test.go`・`bot_expert_test.go`）

- **切り上げ**: 階段を見つけていて、見える範囲に拾う価値のある道具が無く、満腹度・階の滞在ターンが一定を超えたら降りる。突風の前（滞在ターンの上限）には必ず階段へ向かう。11-A の地形の判断（隠し通路を探す）と同じ関数に触れるときは、完了報告に関数名を書いて統合時に合わせる。
- **降りる前**: 敵がいず満腹度に余裕があれば、階段の上で HP を戻してから降りる（今の休憩 `expertShouldRest` の条件を階段の前に広げる）。
- 餓死・突風を増やさないこと（休憩で満腹度を使い切らない）。

### 3. 計測

- 改善ごとに `botFeature` の名前を付け（例: `shopsell`・`shopbuy`・`leavefloor`・`restbeforestairs`）、`-bot.off=<名前>` で個別に切って効果を測る。
- 比較は expert の1500冒険（各難易度500）と `reports/baseline-expert.json`（コマンドは wave11-A の指示書と同じ）。見る数は wave11-0 の「店」「探索」の項目、餓死・突風、難易度別のクリア率、到着時の平均レベル。

## 守ること

- **ゲームのコード・数値は変えない**。不具合を見つけたら直して `regression_test.go` に回帰テストを足し、完了報告に分けて書く。
- クリア率を目標に合わせにいかない（調整は 11-D）。どの難易度のクリア率もベースラインより下げない（ばらつき約 ±3pt を超えて下がる改善は入れないか、`botFeature` で切ったまま残して報告する）。
- `TestBotDoesNotStealFromShop` を残し、売買の経路でも泥棒しないテストを足す。

## 完了条件

- gofmt、`go test -tags test ./...`、`go test ./...`（`TestSimSmoke` を含む）が成功。売る・買う・払えない品を返す・階段の前で休むの小さな盤面のテストを足す。
- expert 1500冒険で違反・ソフトロック・panic 0、BOT 行き詰まり 0、泥棒 0。
- 完了報告は `docs/agents/done/wave11-C.md`（改善ごとの on/off の比較、`botFeature` の名前、AGENTS.md の BOT の説明への追記案、未決事項）。
