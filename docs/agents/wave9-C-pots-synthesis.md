## 作るもの

### 1. 合成（武器・盾・杖）

- 合成の壺（225）: 武器・盾を入れると、壺の中の同じ種類の装備が1つにまとまる。最初に入れた装備が土台になり、後から入れた装備の**能力**と**強化値**（加算）が移る。
  - 能力の印の数の上限は装備ごとに 5（土台の能力を含む。超えた分は移らない）。同じ能力は重ならない。
  - 呪いは移る（呪いが混ざると土台が呪われる）。
  - 杖を2本入れると回数が合わさる（同じ種類のときだけ）。
- 装備に付け足した能力をセーブ・中断再開で保つ（`SavedItem` に省略可能な項目 `ExtraAbilities` を足す。古いセーブも読める）。
- 能力の印を説明画面に表示する（土台の能力と付け足した能力）。

### 2. 壺の追加（ID 226〜239 のうち使う分だけ。残りは予備）

| ID | 名前（仮） | 効果 |
|---|---|---|
| 226 | 識別の壺 | 入れた道具を識別する |
| 227 | 強化の壺 | 入れた武器・盾の強化値を+1（呪いは解けない） |
| 228 | 変化の壺 | 入れた道具が同じカテゴリの別の道具に変わる（入れたときに抽選） |
| 229 | 底抜けの壺 | 入れた道具が消える。割ると周りに罠ができる（不利寄り） |
| 230 | 換金の壺 | 入れた道具が売値（wave10-B の値段表が無ければ仮の値）の所持金に変わる |
| 231 | 背中の壺 | 持っていると、盗む敵・投げ捨てる敵が道具ではなくこの壺の中身を狙う（中身が無ければ壺を） |
| 232 | 冷蔵の壺 | 中の食料が腐らない（腐敗の罠・敵の効果を防ぐ）。取り出せる |

- 壺の容量（3〜5、生成時に抽選）・割れたときの挙動（保存の壺と同じく中身が飛び出す。変化の壺・識別の壺は中身が出る、底抜けは罠）・未識別名・画像（既存の壺の画像の色変えの仮画像でよい）・ヘルプを用意する。
- 吸い出しのカード・壺拡大のカードが新しい壺にも効くことを確かめる。
- BOT: `itemValues` に壺の価値を入れる。使い方（識別・合成）は wave11 で考えるので、BOT は合成の壺を「保存の壺」と同じに扱うだけでよい。
