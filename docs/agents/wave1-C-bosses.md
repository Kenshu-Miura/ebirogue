# wave1-C: ボス3体とボス階（Codex 用）

ブランチ: `agent/wave1-C-bosses`
前提: フェーズ0（特に P0-6「クリア条件と難易度の骨格」）が master にマージ済みであること。
最初に `AGENTS.md` と `docs/agents/README.md` を読み、並列作業のルールに従うこと（`AGENTS.md` と `IMPLEMENTED_FEATURES.md` は編集しない）。

## 作るもの

P0-6 で入れた仮のボスを、本物のボスに置き換える。

| 敵 ID | 階 | 方向性（名前と細部は海老さんの世界観に合わせて提案してよい） |
|---|---|---|
| 42 | 10階 | 甲殻系の大型ボス。殻にこもって一時的に防御が上がる。手下を呼ぶ |
| 43 | 20階 | 大ダコ系のボス。墨で目潰し、プレイヤーとの場所替え、複数回の攻撃 |
| 44 | 30階（最終） | 海竜系の最終ボス。炎と魔法の遠距離攻撃、HP が減ると行動パターンが変わる（2回行動など） |

## 仕様

- `IsBoss: true` を付ける。ランダム出現と `MonsterLevelUpTable` の対象外（上位種は作らない）。
- ボス階は、ボス部屋（大きめの部屋）にボスを配置する。プレイヤーはボス部屋の外から開始する。
- ボスの特殊行動は既存の `SpecialAttack` の仕組みと共通の状態異常処理を使う。封印・睡眠・混乱・金縛りなどへの耐性は、ボスごとに決めて定数化する。
  即死級の効果（全滅のカード、ジェノサイドのカード、シフトチェンジの杖など）がボスに効くかどうかも決め、テストする。
- ボスを倒したときのメッセージを追加する。目標階のボスを倒したときのクリア処理は P0-6 の仕組みをそのまま使う。
- ボスの画像は 30x30 の透過 PNG を仮作成してよい（既存の敵画像の色相を変えたものでも可）。仮画像は完了報告に列挙する。
- ヘルプの「特殊な敵」ページにボスの説明を追加する。

## バランスの確認

- `go test -run TestSimBatch -count=1 -timeout 0 . -args -sim.runs=300 -sim.difficulty=all` を実行し、ボス階での死亡率とボス撃破率をレポートから抜き出す。
- ボス戦での死亡率が極端（ほぼ0%、またはほぼ100%）なら能力値を調整する。最終的な数値と、調整前後のレポートの要点を完了報告に書く。
